用字母表示数

数与代数式与方程课标：理解课标必达

字母能表示变化的数和数量关系；a² 是 a 乘 a，2a 是 a 加 a，一字之差意思完全不同。

所属主题式与方程
所属模块数与代数
课标学段第三学段（5~6年级）
前置知识乘法运算律
核心素养符号意识推理意识模型意识

课标要求

数与代数·数量关系

在具体情境中，探索用字母表示事物的关系、性质和规律的方法，感悟用字母表示的一般性（例19）。

印刷第 24 页　行为动词：探索

说明

用小棒摆三角形：摆 1 个用 3 根，摆 2 个用 6 根，摆 3 个用 9 根……照这样写下去，永远写不完。于是请一个能变的数来站位置，用字母 n 表示摆了几个，那么用的小棒就是 3n 根。n 可以是 1、2、3、10、100，代进去就能算出对应的根数。字母能表示一个变化的数。

字母还能表示数量关系。苹果每千克 a 元，买 b 千克，一共 ab 元——不管单价是 6 元还是 8.5 元，也不管买几千克，这一句话把所有情况都说完了。长方形的面积 S = ab、路程 s = vt、运算律 a + b = b + a，都是用字母把关系一次说清。

写字母式有几条约定：字母与字母相乘，乘号可以写成「·」或者干脆省略，a × b 写成 ab；数与字母相乘，数要写在字母前面，3 × n 写成 3n，不写 n3；1 与字母相乘，1 省略不写，1 × a 就写 a。加号、减号、除号不能省。

最容易混的是 a^2 和 2a：a^2 读作「a 的平方」，表示 a × a，两个 a 相乘；2a 表示 a + a，两个 a 相加。当 a = 3 时，a^2 = 3 × 3 = 9，而 2a = 2 × 3 = 6，差了 3。只有当 a = 2（或 a = 0）时它们碰巧相等，绝不能当成一回事。

字母表示的数还要符合实际情况：a 表示人数，就不能取 0.5；表示长度，就不能取负数。字母式后面带单位时，整个式子要加括号，写成「(a + 28) 岁」，不能写成「a + 28 岁」。

使用场景

摆图形找规律：用小棒摆正方形，摆 n 个用 3n + 1 根；摆三角形，摆 n 个用 3n 根。规律一句话就写完了。

购物算钱：苹果每千克 a 元，买 b 千克，总价 ab 元；知道 a 和 b 的具体数，代进去就能算。

行程问题：地铁每分钟行 v 米，行 t 分钟，路程 vt 米——公式本身就是字母式。

家庭与年龄：小明今年 a 岁，爸爸比他大 28 岁，爸爸今年 (a + 28) 岁；n 年后爸爸就是 (a + n + 28) 岁。

手机套餐：每月用 x GB 流量，一年就是 12x GB，换成哪个月都能算。

注意点

数要写在字母前面。3 × n 写成 3n，不写 n3——n3 容易被看成「n 加 3」或者一个两位数。

a^2 不是 2a。a^2 = a × a，2a = a + a；a = 5 时，a^2 = 25，2a = 10，差了 15。

只有字母与字母、数与字母之间的乘号能省。3 × 4 不能写成 34，那是把两个数拼成了一个数。

1a 要写成 a。1 和字母相乘，1 省略不写；同理 a × 1 也写 a。

字母的取值要符合实际。a 表示人数只能是自然数，表示长度不能是负数；写「a 岁」的答案时要检查是否合理。

带单位时整个式子加括号。(a + 28) 岁、(3n + 1) 根，别写成 a + 28 岁。

为什么是这样

算理推导

  1. 先看只用数会怎样：摆 1 个三角形写 3，摆 2 个写 6，摆 3 个写 9。每写一个数只管一种情况，想知道摆 100 个用几根，还得重新算。想要一句话管住所有情况，就得请一个「能变的数」来占位——这就是字母。

  2. 字母凭什么能代表那么多数？因为式子里真正稳定的不是那个数，而是数与数之间的关系：不管摆几个，小棒数总是个数的 3 倍。字母 n 只是把「几个」这个位置空出来，3n 把这个关系固定住了。换 n，答案自己跟着变。

  3. 为什么 a^2 和 2a 不一样？a^2 是边长 a 的正方形的面积，是「面」；2a 是两条长 a 的边接起来，是「线」。a = 4 时，正方形面积是 16 平方厘米，两条边接起来只有 8 厘米，一个是平方单位、一个是长度单位，本来就不是一回事。

  4. 为什么数要写在字母前？3n 读作「3 个 n」，正好和乘法「几个几」的说法一致：3 个 n 就是 n + n + n。写成 n3 既不好读，又容易和「n 与 3 组成的两位数」混起来。

  5. 为什么字母能把规律说清？加法交换律写成 a + b = b + a，一个式子对所有数都成立；要是举例子，1 + 2 = 2 + 1、3 + 5 = 5 + 3，举到明年也举不完。字母的厉害之处，就在于用一行字代替了无数行例子。

动手实验

用小棒摆正方形：摆 1 个用 4 根，摆 2 个用 7 根，摆 3 个用 10 根。把个数和根数填进表格，看每次多几根——每多一个正方形，只多 3 根（第一条边共用）。于是 n 个正方形要 3n + 1 根。用 n = 4 验算得 13 根，用 n = 10 验算得 31 根，再实际摆一摆数一数，对上了就说明这个字母式靠得住。

按场景的例题

例 1（场景：校园生活）　数学活动课上摆小棒

用小棒摆正方形（每个正方形共用一条边），摆 n 个正方形需要多少根小棒？摆 8 个呢？

解：摆 1 个用 4 根，摆 2 个用 7 根，摆 3 个用 10 根：每多摆一个正方形只多 3 根（有一条边共用），所以是 3n + 1 根。当 n = 8 时，3 × 8 + 1 = 25。

答：(3n + 1) 根；摆 8 个要 25 根。

例 2（场景：购物消费）　水果店买苹果

苹果每千克 a 元，买 2.5 千克要付多少元？当 a = 8 时，一共多少元？

解：总价 = 单价 × 数量 = a × 2.5 = 2.5a（元）。当 a = 8 时，2.5 × 8 = 20。

答：2.5a 元；a = 8 时是 20 元。

例 3（场景：家庭与年龄）　家里的年龄问题

小明今年 a 岁，爸爸比他大 28 岁。爸爸今年多少岁？当 a = 11 时呢？

解：爸爸的年龄 = a + 28，写作 (a + 28) 岁。当 a = 11 时，11 + 28 = 39。

答：(a + 28) 岁；小明 11 岁时爸爸 39 岁。

例 4（场景：行程出行）　地铁的行驶路程

地铁每分钟行 v 米，行 8 分钟能行多少米？当 v = 600 时呢？

解：路程 = 速度 × 时间 = v × 8 = 8v（米）。当 v = 600 时，8 × 600 = 4800。

答：8v 米；v = 600 时是 4800 米。

常用推论

  • 长方形的面积 S = ab、周长 C = 2(a + b)；正方形的面积 S = a^2、周长 C = 4a——公式都是字母式。

  • 运算律的字母式：a + b = b + a，(a + b) + c = a + (b + c)，ab = ba，(a + b)c = ac + bc。

  • 总价 = 单价 × 数量，可写成总价 = ab；路程 = 速度 × 时间，可写成 s = vt。

  • 同一个字母在同一个式子里表示相同的数，不同字母可以表示不同的数；字母取不同的值，式子的结果就跟着变。

易错点

错a = 5 时，把 a^2 算成 2 × 5 = 10。

为什么错把「平方」当成了「乘 2」。a^2 是两个 a 相乘，2a 才是两个 a 相加。

正确a^2 = 5 × 5 = 25，2a = 2 × 5 = 10，两者差 15。

错把 3 × n 写成 n3。

为什么错数与字母相乘，数要写在字母前面，这是约定，也符合「3 个 n」的读法；写成 n3 还容易被看成一个两位数。

正确写成 3n，读作「3 个 n」。

错把 3 × 4 也省成 34。

为什么错省略乘号只用在含字母的乘法里。两个数相乘省掉乘号，就变成一个两位数了，意思全变。

正确两个数相乘照写 3 × 4；只有 3 × n 才写成 3n。

错爸爸比小明大 28 岁，小明 a 岁时写成「爸爸 a + 28 岁」。

为什么错整个式子后面带单位时要加括号，否则容易读成「a 加上 28 岁」，把数和单位拆开了。

正确写成「爸爸 (a + 28) 岁」。

直观理解

字母像一个写着名字的储物盒：盒子上标着 n，里面装几个由你定，今天装 3 个、明天装 100 个都行；3n 就是「三个这样的盒子」。a^2 是边长 a 的一块方布，2a 是两根长 a 的绳子接起来——一块布和一根绳，当然不能混为一谈。

字母站个位，数儿随便换；数字写前头，乘号可不见；a 的平方是自乘，2a 是两个添。

关联知识点

本知识点指向

  • 乘法运算律前置：四年级已经用字母写过乘法运算律，这里是把它讲透
  • 平行四边形的面积应用：S = ah 就是字母式，底和高取不同的值，面积跟着变
  • 三角形的面积应用：S = ah ÷ 2 把「底乘高再一半」这个关系固定在一行字里

指向本知识点

  • 和倍问题进阶：用字母表示数以后，「小数的 3 倍」可以写成 3x，和就是 x + 3x = 96，份数关系一眼看清
  • 方程的意义与解方程前置：先会用字母表示未知数，才写得出含未知数的等式
  • 常用的数学思想和方法对应：用字母把「第几个」和「是多少」一一对上
