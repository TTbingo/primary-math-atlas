印刷第 20 页　行为动词：掌握

说明

遇到一个大数，比如 380004500，不要一位一位硬读。正确做法是分级：从右往左每四位划一道线。

3\textbf|8000\textbf|4500——最右边四级是个级（4500），中间是万级（8000），最左边是亿级（3）。

分级之后，每一级都像一个独立的四位数那样读，读完在后面加上这一级的名字：亿级加「亿」，万级加「万」，个级什么都不加。于是上面这个数读作：三亿八千万四千五百。

写数反过来：听到「三亿」，先写 3；听到「八千万」，在万级写 8000；听到「四千五百」，在个级写 4500。哪一级没有数，就用四个 0 把那一级占满，不能空着不写。

（小数、分数、百分数的读写）

小数：整数部分按整数的读法读，小数点读作「点」，小数部分依次读出每一个数字。比如 12.35 读作十二点三五，不是「十二点三十五」；0.408 读作零点四零八，中间的 0 必须读出来。

分数：先读分母，再读分子，中间用「分之」连接。3/4 读作四分之三，7/10 读作十分之七。写的时候正好相反——先写分数线，再写分母，最后写分子。

百分数：% 读作「百分之」，所以 25% 读作百分之二十五，不读「二十五百分号」。写的时候先写数字，再写百分号。

三类数读法不同，是因为它们的结构不同：小数是「按位累加」，每一位都是独立的计数单位；分数是「先分几份、取了几份」的两段式；百分数干脆就是一个「以 100 为基准的比例」。

使用场景

看新闻里的数字：人口、GDP、票房，动辄七八位数，不分级根本读不出来。

快递单号与订单号：十几位的编号，分段念才不会念串行。

图书馆索书号：按级分段，先找大类再找小类。

手机存储空间：128G、512G 后面的字节数是个十来位的天文数字。

看地图比例尺下的实际距离：常常是几万米、几十万米。

（小数、分数、百分数的读写）

体检报告：身高 1.42 米、视力 4.9，都是小数，读数时小数部分要一位位念。

菜市场称重：电子秤显示 2.30 千克，末尾的 0 要读出来，表示精确到百分位。

食谱配比：「糖占面粉的 1/5」，读作五分之一。

手机电量与折扣：电量 78%、全场 8 折（即 80%），读作百分之七十八、百分之八十。

体育成绩：跑步用时 9.58 秒，读作九点五八秒。

注意点

分级必须从右往左划，不能从左往右。从左往右划出来的级是错的。

每一级最多只能有四位，写满四位，下一位就要落到更高级去。看到某级写了五位数，一定是分错了。

只有最左边那一级（最高级）可以不满四位，其余每一级都必须写满四位、不足补 0；分级线永远从右往左每四位一道。

读数时「零」的规则：每级末尾的 0 都不读；一级里中间连续几个 0 只读一个「零」；一级全是 0 时，这一级整个不读，但要读一个「零」来占位（当它左边还有更高级时）。

（小数、分数、百分数的读写）

小数部分不能按整数读。0.35 是零点三五，不是零点三十五；1.20 是一点二零，不是一点二十。

小数部分中间的 0 必须读，末尾的 0 也要读。0.05 读作零点零五，2.30 读作二点三零——末尾的 0 表示精确到哪一位，删掉会改变精度含义。

分数要先读分母。很多人顺口读成「三分之四」，那其实是 4/3 的读法。

百分数不读「百分号」三个字，只读「百分之几」。

带分数读法：21/3 读作二又三分之一，中间的「又」不能省。

为什么是这样

算理推导

  1. 先问一个笨问题：为什么非要四位一级？因为我们的计数法是十进制，而汉语里每四位就有一个新的大单位——个、十、百、千，然后是万；万、十万、百万、千万，然后是亿。

  2. 也就是说，「万」是第 5 位，「亿」是第 9 位。所以从右往左数到第 5 位划一道线，第 9 位再划一道，正好把数分成个级、万级、亿级。

  3. 分级之后每一级内部的读法完全一样——都是「几千几百几十几」。所以你只要会读四位数，就会读任意大的数：一级一级读，读完加个级名。

  4. 写数时反过来想级别：听到「亿」就往亿级写，听到「万」就往万级写。关键是没听到的那一级不能跳过，要用 0 占位。

  5. 举个例子：「五亿零三十万」。亿级是 5，万级是 0030（因为说的是三十万，万级只有后两位有数，前两位补 0），个级是 0000。合起来：5 0030 0000。

  6. （小数、分数、百分数的读写）

  7. 先看小数：小数部分的每一位都有自己的计数单位——第一位是十分之一，第二位是百分之一，第三位是千分之一。它们是并列的、各自独立的，不是拼成一个整数。

  8. 所以 0.35 其实是在说「3 个十分之一和 5 个百分之一」，而不是「35 个什么」。既然每一位独立，读的时候就只能一位位念：三五。

  9. 这也是为什么 0.35 和 0.305 读起来完全不同——后者的 0 占住了百分位，必须读出来，否则两个数就混了。

  10. 再看分数：3/4 这个记号本身是两步操作——下面的 4 说「平均分成 4 份」，上面的 3 说「取其中 3 份」。先有分才有取，所以读法也跟着先读分母（四）、再读分子（三）。

  11. 最后是百分数：% 这个符号已经把「除以 100」的意思打包进去了，所以读成「百分之」最省事，25% 就是「以 100 为基准取 25」。它本质上是一个省掉了分母 100 的分数。

  12. 三套读法对应三种结构，死记容易混，理解了为什么就不会错。

动手实验

拿三个数练手：4050000、400005、40500005。先分级，再读出来，然后倒过来：只读给同桌听，让他写出来，看能不能还原成原数。你会发现最容易出错的就是中间那一级——要么多读一个零，要么少读一个零。把这三个数读错的版本也写下来对照，印象最深。 （小数、分数、百分数的读写） 找四个容易读错的数：0.35、0.305、3/4、25%。先按自己的第一反应读一遍并录下来，再按规则读一遍对比。重点体会 0.35 与 0.305 的差别——试着把 0.305 中间的 0 省掉读成「零点三五」，看看它是不是变成了另一个数。答案：是的，它变成了 0.35。小数部分的 0 是占位的，不是装饰。

按场景的例题

例 1（场景：校园生活）　读图书馆的藏书量

学校图书馆有藏书 3064000 册，这个数怎么读？

解：分级：306\textbf|4000。万级是 306，读作三百零六万；个级是 4000，读作四千。合起来：三百零六万四千。

答：读作：三百零六万四千册。

例 2（场景：物流运输）　写快递系统里的年度订单量

「九亿零八百万」怎么写？

解：亿级：9；万级：0800（八百万，前一位补 0）；个级：0000。合起来 9 0800 0000。

答：写作 908000000。

例 3（场景：家庭与年龄）　读家庭年度支出

一个数读作「四千零五万零二十」，这个数写作什么？

解：万级是 4005；个级是 0020。合起来 40050020。注意个级只有「二十」，前面两位要补 0。

答：写作 40050020。

例 4（场景：计量与估算）　读手机存储空间的字节数

128000000000 怎么读？

解：分级：1280\textbf|0000\textbf|0000。亿级是 1280，读作一千二百八十亿；后面两级全 0，都不读。

答：读作：一千二百八十亿。

例 5（场景：校园生活）　读体测成绩

小明的身高是 1.42 米，体重是 38.5 千克，这两个小数怎么读？

解：整数部分按整数读，小数点读「点」，小数部分依次读数字。1.42 读作一点四二；38.5 读作三十八点五。

答：一点四二米；三十八点五千克。

例 6（场景：饮食与配比）　照着食谱配奶茶

食谱写着「糖占牛奶的 1/5，珍珠占 3/10」，这两个分数怎么读？各表示什么？

解：先读分母再读分子：1/5 读作五分之一，表示把总量平均分成 5 份取 1 份；3/10 读作十分之三。

答：读作五分之一、十分之三。

例 7（场景：购物消费）　看商场打折牌

牌子上写着「全场 75%」，这个数怎么读？它表示的是什么意思？

解：75% 读作百分之七十五，表示以 100 为基准取 75，也就是原价的 75/100。

答：读作百分之七十五，即按原价的 75/100 出售。

例 8（场景：计量与估算）　读电子秤上的重量

电子秤显示 2.30 千克，有人读成「二点三千克」，对吗？

解：不对。小数部分的 0 虽然不影响大小，但它表示精确到百分位，读数时要读出来：二点三零。

答：应读作二点三零千克。

常用推论

  • 分级线画法：从右往左每四位一道，最左边可以不满四位。

  • 末尾 0 不读：每级末尾的 0 一律不读，所以 4500 读作四千五百，不是四千五百零零。

  • 中间 0 只读一个：一级内部连续几个 0，只读一个「零」。

  • 整级为 0 的处理：万级全是 0 而亿级有数时，要读一个「零」占位，如 5 0000 3000 读作五亿零三千。

  • 小数位数 = 精确程度：小数点后有几位，就表示精确到那一位，读的时候一个都不能省。

  • 分母是 10、100、1000 的分数可以直接写成小数：7/10 = 0.7，7/100 = 0.07。

  • 百分数就是分母为 100 的分数：25% = 25/100 = 0.25，所以三种数可以互相转化。

  • 带分数的读法：整数部分 + 「又」 + 分数部分，如 21/3 读作二又三分之一。

易错点

错把 40050020 读成「四千零五万零二百」。

为什么错个级是 0020，读作「零二十」，不是「二百」。把 0020 看成 0200 了。

正确分级后个级是 0020，读作四千零五万零二十。

错把 3064000 读成「三百零六万四千零百」。

为什么错个级 4000 的 0 都在级末，一律不读，更不该读出「零百」这种说法。

正确读作三百零六万四千。

错写「九亿零八百万」时写成 980000000。

为什么错漏了亿级和万级之间的 0。亿级 9、万级 0800、个级 0000，万级那一位 0 必须补上。

正确写作 908000000。

错分级时从左往右划：3|8000|4500 划成 3800|0450|0。

为什么错分级必须从右往左，因为低位是固定的，高位才可能不满四位。

正确从右往左：3\textbf|8000\textbf|4500。

错把 0.35 读成「零点三十五」。

为什么错把小数部分当成整数读了。3 在十分位、5 在百分位，是两个独立的计数单位，不是一个整体 35。

正确读作零点三五。

错把 0.305 读成「零点三十五」或「零点三五」。

为什么错中间的 0 占着百分位，省掉后这个数就变成 0.35 了，数值完全改变。

正确读作零点三零五。

错把 3/4 读成「三分之四」。

为什么错读反了顺序。分数规定先读分母再读分子，「三分之四」其实是 4/3。

正确读作四分之三。

错把 25% 读成「二十五百分号」。

为什么错% 这个符号读作「百分之」，不是「百分号」。口语里不读符号名。

正确读作百分之二十五。

直观理解

把多位数想成一本书：个级是第一册，万级是第二册，亿级是第三册。每册最多四页，页码从右往左编。读书的时候一册一册念，念完一册报个册名。哪一册是空的，就用四个 0 把那册填满，不能让它凭空消失。分级线就是书脊——划对了，再长的数也能一册册读完。 （小数、分数、百分数的读写） 三种数讲的是三种不同的事，读法自然不同。小数像报电话号码，每一位独立报出来；分数像说菜谱，「先分成几份、取了几份」，顺序不能颠倒；百分数像打折扣，「以一百为基准取了几」。只要记住每类数在「说什么事」，读法就跟着出来了，不用硬背。

大数读法并不难，四位一级从右分。个级万级和亿级，读完加名记在心。级末的零都不读，中间连续读一声。哪级空着四个零，占位千万别漏空。 （小数、分数、百分数的读写） 小数读法最简单，整数照读点在后。小数部分逐个念，末尾的零也要留。分数先读分母来，分之中间再读上。百分数，读百分之，百分号字别出口。
