说明

比较两个数的大小，用三个符号：大于号 >、小于号 <、等号 =。符号的开口永远朝着大的那个数，尖头朝着小的那个数，所以 5 > 3、3 < 5 说的是同一件事，只是从不同方向读。

整数比大小，先看位数。 位数不同，位数多的那个大：四位数一定比三位数大，因为四位数的最高位是千位，千位上的一个就顶十个百。位数相同，就从最高位起一位一位往下比，谁先大谁就大，后面的位不用再看。

小数比大小，先比整数部分，再比小数部分。 整数部分谁大谁就大；整数部分相同，就比十分位；十分位相同，再比百分位，一位一位往下走。走的顺序和整数完全一样，只是数位往右延长了。

小数部分的位数常常不一样，这时候先在小数末尾补 0，把位数补齐再比。0.5 补成 0.50，大小一点没变，因为 5 个 0.1 正好就是 50 个 0.01。补齐之后相同数位上下对齐，逐位比较就不会错位。

最要记住的一点：小数比大小不是比谁位数多，也不是比谁数字串长。0.5 只有一位小数，0.45 有两位，可 0.5 更大。比的是相同数位上「有几个这样的计数单位」，不是哪个数写得更长。

（分数比较大小）

整数和小数比大小，数位一对齐就行。分数不一样：分子和分母两个数同时在变，光看哪个数字大，一定出错。所以比分数之前，先想办法让其中一个变成相同的，或者干脆把分数换成小数。

第一条路：同分母比分子。 分母相同，说明每一份的大小相同，都是同一个分数单位，那么取几份谁多，谁就大。七分之三小于七分之五，因为都是七分之一，5 份比 3 份多。

第二条路：同分子比分母。 分子相同，说明取的份数一样多，但分母越大，每一份被切得越细、越小，所以分母大的那个分数反而小。五分之三大于八分之三，五分之一比八分之一大，同样取 3 份，当然是五分之三大。

第三条路：分子分母都不同。 两条道可选：一是通分，把两个分母化成相同的数，一般取最小公倍数，再按第一条路比；二是化成小数，各算各的值，再比小数。五分之三与八分之五，通分得四十分之二十四与四十分之二十五，所以五分之三小；化成小数是 0.6 与 0.625，结论一样。

怎么挑最省事？ 分母成倍数关系时通分最快，比如四分之一与八分之三，把前者改成八分之二就行；分母互质、数字又大时化成小数更快，比如十一分之七与十三分之九；如果一个比 1 大、一个比 1 小，不用算就能下结论。

（正负数比较大小）

生活里有一类量必须用两个方向来说：零上与零下、收入与支出、海平面以上与以下。为了把它们写进算式，人们引入了正数和负数：零上 3 摄氏度记作 +3℃，零下 3 摄氏度记作 -3℃。0 是分界线，它既不是正数，也不是负数。

把所有数排在一条直线上，就是数轴：先定一个 0（原点），再定向右为正方向，最后定好每一格代表多少。数轴上有一条永远成立的规律：右边的数总比左边的大。判断正负数的大小，最可靠的办法就是看它在数轴上的位置。

由此马上得到两条：正数都大于 0，负数都小于 0，所以正数一定大于负数。+3 在 0 右边，-3 在 0 左边，所以 -3 < 0 < +3。

两个负数比大小：负号后面的数越大，这个负数反而越小。 -5 表示从 0 往左走 5 步，-2 表示往左走 2 步；往左走得越远，位置越靠左，数就越小，所以 -5 < -2。-5℃ 比 -2℃ 更冷，欠 5 元比欠 2 元更糟，说的都是这件事。

比较三个以上的数时，不必慌张：先把它们分成正数、0、负数三堆，每一堆内部按原来的办法比，最后按「正数堆 > 0 > 负数堆」的顺序接起来。比如把 3、-5、0、-2 排序，正数堆只有 3，负数堆里 -5 小于 -2，结果就是 -5 < -2 < 0 < 3。

容易错的原因在这里：负号相当于把方向掉了个头。5 和 2 比，本来 5 大；都加上负号、都往 0 左边走之后，走得更远的那个反而更小。所以比较两个负数时，先看负号后面的数，再把大小结论反过来。

使用场景

超市比价：同款牛奶一家 3.5 元、一家 3.45 元，差几毛也要比清楚。

运动会成绩：跳远 3.05 米、3.5 米、2.98 米，谁第一谁第三要排准。

体检数据：身高 1.4 米和 1.45 米看着差不多，一比才知道差半分米。

快递称重：2.5 千克和 2.05 千克的包裹，运费档位可能就不一样。

（分数比较大小）

班级人数占比：一班男生占八分之五，二班占五分之三，哪个班男生比例高？

照着配方做点心：一个方子放三分之二杯糖，另一个放四分之三杯，哪个更甜？

看行程进度：已走全程的五分之三和八分之五，哪个走得多？

比较地块：两块菜地分别有七分之四、九分之五种上了菜，哪块种得更满？

（正负数比较大小）

天气预报：北方城市 -18℃、南方城市 -7℃，谁更冷要说清楚。

海拔高度：吐鲁番盆地 -155 米、死海 -430 米，负数比的是谁更低。

家庭账本：这个月结余 -120 元、上个月 -85 元，哪个月手头更松。

地下空间：地铁站台在 -12 米、地下车库在 -8 米，哪个更深。

注意点

要按相同数位比，不是按数字大小比。十分位上的 4 和十分位上的 5 才有可比性，不能拿百分位的 5 去比十分位的 4。

补 0 只能补在末尾。0.5 补成 0.50 大小不变，补成 0.05 就变成原来的十分之一了。

带单位的量先统一单位再比。1.2 米和 95 厘米不能直接比 1.2 和 95，要先把 95 厘米化成 0.95 米。

排顺序时看清要求。从小到大用 < 连，从大到小用 > 连，写反了意思就全错。

（分数比较大小）

通分时分子要跟着变。分母乘了几，分子也要乘几，分数的大小才不变。

化成小数比较时，除不尽就保留同样多的位数，都保留三位再比，不能一个两位一个三位。

别把分子加分子、分母加分母去比，那算出来的是另一个数，不是分数的大小。

答案要用原数写。通分只是为了比，回答时还得写原来那两个分数，别把通分后的数当成答案。

（正负数比较大小）

别把负号去掉再比。去掉负号得到的是它离 0 的距离，这个距离的大小关系与负数本身的大小关系正好相反：离 0 越远的负数越小。

0 不是「无所谓」的数。它比所有负数都大，比所有正数都小，是正负数的分界线。

带单位的负数要先统一单位。-5℃ 和 -8℃ 可以直接比，但 -5℃ 和 -2 米没有可比性。

负数不一定比正数「小很多」，但一定更小。-0.1 看着不起眼，它照样小于 0，也小于任何正数。

答语要说清方向。说「-5 更小」还不够，回答冷不冷、低不低时，要落到具体的量上：-5℃ 更冷。

为什么是这样

算理推导

  1. 先想清楚整数为什么位数多就大：三位数的最高位是百位，四位数的最高位是千位，而千位上的一个就相当于十个百。高位一旦多出一级，低位写满也追不上。

  2. 位数相同时，从最高位比起：百位分出胜负就停；百位打平，再看十位；十位打平，再看个位。前面的位一旦定了胜负，后面的位再大也翻不了盘。

  3. 小数沿用同一套思路，只是把数位往右延长：整数部分之后是十分位、百分位、千分位，计数单位一个比一个小。所以先比整数部分，再比十分位，再比百分位。

  4. 位数不同容易错位：0.5 的 5 在十分位，0.45 的 4 在十分位、5 在百分位。把小数点对齐、末尾补 0 写成 0.50 与 0.45，相同数位就上下对齐了，逐位一看便知。

  5. 补 0 为什么不变大小？0.5 是 5 个 0.1，而 50 个 0.01 也是 5 个 0.1，所以 0.5 与 0.50 完全相等。补 0 只是换了一种数法，没有改变量。

  6. （分数比较大小）

  7. 先想清楚分母和分子各管什么：分母是把整体平均切成几份，分子是取了几份。两块蛋糕一块切 5 份、一块切 8 份，这个「一份」本身就不一样大。

  8. 所以直接数份数没有意义：五分之三的 3 份和八分之五的 5 份，每份大小不同，份数多不代表总量多。要先把「一份」变成同样大，这一步就是通分。

  9. 通分找分母的最小公倍数：5 和 8 的最小公倍数是 40。五分之三等于四十分之二十四，八分之五等于四十分之二十五，现在每份都是四十分之一。

  10. 每份一样大了，比块数就行：25 块比 24 块多，所以八分之五大。

  11. 也可以绕开「份」，直接算分数值多少再比：五分之三是 0.6，八分之五是 0.625。两条路殊途同归，选顺手的走。

  12. （正负数比较大小）

  13. 先承认一条最根本的规律：数轴上右边的数比左边的大。这条规律对所有的数都成立，正数、0、负数一视同仁。

  14. 再看位置：正数在 0 的右边，负数在 0 的左边。所以正数一定大于 0，0 一定大于负数，正数一定大于负数。

  15. 负号表示方向朝左。-5 是从 0 向左走 5 格，-2 是从 0 向左走 2 格。走 5 格比走 2 格走得更远，落点更靠左。

  16. 更靠左就更小，于是 -5 < -2。所以两个负数比大小，负号后面的数大的那个反而小，结论与正数相反。

  17. 用生活里的量核对一遍：-5℃ 比 -2℃ 冷，-430 米比 -155 米低，欠 5 元比欠 2 元更糟。三种情境给出同一个方向，说明这条规律靠得住。

动手实验

在数位顺序表上把 3.5 和 3.45 写下来，要求小数点上下对齐，空着的格子补 0，写成 3.50 与 3.45。然后画一条数轴，标出 3.4、3.45、3.5、3.6 四个点，看看 3.45 和 3.5 谁在右边。最后把 0.5 与 0.45、2.5 与 2.05 各比一次，验证「位数多不一定大」。 （分数比较大小） 剪两条一样长的纸条。第一条折成 5 等份、涂 3 份；第二条折成 8 等份、涂 5 份。并排一放，看不出谁长，这就说明「份数多」不等于「涂得多」。再把两条都换成 40 格的方格纸，分别涂 24 格和 25 格，一眼就分出来了。 （正负数比较大小） 在纸上画一条从 -6 到 6 的数轴，每格标一个整数，把 -5、-2、0、3 用圆点标出来，逐个说出「谁在谁右边」。再用一支温度计模型（纸条上画刻度），从 0℃ 往下数 5 格和 2 格，看哪一格更靠下、哪个温度更低。最后数一数 -5 与 -2 各自离 0 有几格，对照「离 0 越远的负数越小」。

按场景的例题

例 1（场景：购物消费）　两家店买同款牛奶

同款牛奶，甲店 3.5 元一盒，乙店 3.45 元一盒。哪家便宜？便宜多少元？

解：把 3.5 补成 3.50，与 3.45 逐位比：整数部分都是 3，十分位 5 > 4，所以 3.5 > 3.45。差价 3.50 - 3.45 = 0.05 元。

答：乙店便宜，便宜 0.05 元，也就是 5 分钱。

例 2（场景：校园生活）　运动会跳远比赛

三名同学的跳远成绩是 3.05 米、3.5 米、2.98 米。请从远到近排出名次。

解：先看整数部分：2.98 的整数部分是 2，最小，排第三。3.05 与 3.5 整数部分都是 3，比十分位：0 < 5，所以 3.05 < 3.5。

答：3.5 米第一，3.05 米第二，2.98 米第三。

例 3（场景：计量与估算）　体检量身高

小丁身高 1.4 米，小果身高 1.45 米。谁高？高多少厘米？

解：1.4 补成 1.40，与 1.45 比：整数部分同为 1，十分位同为 4，百分位 0 < 5，所以 1.4 < 1.45。差 1.45 - 1.40 = 0.05 米，即 5 厘米。

答：小果高，高 5 厘米。

例 4（场景：物流运输）　寄快递称重

两个包裹分别重 2.5 千克和 2.05 千克。哪个重？重多少千克？

解：2.5 补成 2.50，与 2.05 比：整数部分同为 2，十分位 5 > 0，所以 2.5 > 2.05。差 2.50 - 2.05 = 0.45 千克。

答：2.5 千克的包裹重，重 0.45 千克。

例 5（场景：上学日常）　比较两个班的男生占比

一班男生占全班的 5/8，二班男生占全班的 3/5。哪个班男生占比高？

解：分母 8 和 5 的最小公倍数是 40：5/8 = 25/40，3/5 = 24/40。25 > 24，所以 5/8 > 3/5。

答：一班的男生占比高一些。

例 6（场景：饮食与配比）　两个配方比甜度

甲配方放糖 2/3 杯，乙配方放糖 3/4 杯，两杯一样大。哪个配方更甜？

解：通分，公分母取 12：2/3 = 8/12，3/4 = 9/12。8 < 9，所以 2/3 < 3/4。

答：乙配方更甜。

例 7（场景：行程出行）　徒步走完全程

上午走了全程的 3/5，下午走了全程的 5/8。哪一段走得多？

解：化成小数比：3/5 = 0.6，5/8 = 0.625，0.6 < 0.625，所以 3/5 < 5/8。

答：下午走得多。

例 8（场景：农业生产）　两块菜地的种植进度

两块同样大的菜地，甲块种了 4/7，乙块种了 5/9。哪块种得更满？

解：分母 7 和 9 互质，公分母是 63：4/7 = 36/63，5/9 = 35/63。36 > 35，所以 4/7 > 5/9。

答：甲块种得更满。

例 9（场景：自然现象）　看两地气温

某日哈尔滨最低气温 -18℃，北京最低气温 -7℃。哪个城市更冷？

解：-18 与 -7 都是负数，看负号后面的数：18 > 7，负号后面的数大的反而小，所以 -18 < -7。

答：哈尔滨更冷，-18℃ 比 -7℃ 低 11℃。

例 10（场景：工程建造）　比较两处低地

吐鲁番盆地最低处海拔约 -155 米，死海湖面海拔约 -430 米。哪个地方更低？

解：两个都是负数，-430 离 0 更远、位置更靠左，所以 -430 < -155。

答：死海更低，比吐鲁番盆地低 275 米。

例 11（场景：金融理财）　记家庭月度结余

小果家这个月结余 -120 元，上个月结余 -85 元。哪个月的收支情况好一些？

解：-120 与 -85 都是负数，120 > 85，负号后面的数大的反而小，所以 -120 < -85。

答：上个月好一些，这个月多花了 35 元。

例 12（场景：绿化照明）　比较地下设施的深度

地铁站台的地面标高是 -12 米，地下车库是 -8 米。哪个更深？深多少米？

解：-12 离 0 有 12 格，比 -8 的 8 格更远、位置更靠左，所以 -12 < -8。

答：地铁站台更深，深 4 米。

常用推论

  • 整数比大小：位数多的数大；位数相同，从最高位起逐位比较，先分出大小的一方为大。

  • 小数比大小：先比整数部分，整数部分相同再依次比十分位、百分位、千分位。

  • 小数末尾添 0 或去 0，大小不变，所以位数不同时可以先补齐再比。

  • 小数位数的多少不决定大小：0.5 > 0.45，0.9 > 0.888。

  • 两个数比较，若整数部分相差 1 以上，小数部分再长也改变不了结论。

  • 同分母的两个分数，分子大的那个大。

  • 同分子的两个分数，分母大的那个反而小。

  • 分子分母都不同时：通分成同分母再比，或化成小数再比。

  • 真分数都小于 1，假分数都不小于 1，带分数都大于 1，先分类能省不少计算。

  • 两个分数都比 1 小一点时，可以看它们各自差多少到 1，差得少的那个大。

  • 正数都大于 0，负数都小于 0，正数大于一切负数。

  • 数轴上右边的数总比左边的大，这是判断所有数大小的通用依据。

  • 两个负数比大小：负号后面的数大，这个负数反而小。

  • 0 既不是正数也不是负数，它比任何负数都大、比任何正数都小。

  • 两个负数比较，负号后面的数相等，两数就相等，例如 -3 与 -3。

易错点

错认为 0.45 > 0.5，理由是 45 比 5 大。

为什么错这是把小数当成整数在比。小数比的是相同数位上的计数单位个数：0.45 的十分位是 4，0.5 的十分位是 5，十分位一开比就分出胜负，百分位上的 5 根本轮不到发言。

正确把 0.5 补成 0.50，与 0.45 逐位比，十分位 5 > 4，所以 0.5 > 0.45。

错比较 3.5 和 3.45 时，觉得 3.45 的小数位数多，所以 3.45 大。

为什么错位数多只说明写得更细，不代表量更大。补齐成 3.50 与 3.45 后看十分位，5 比 4 大。

正确3.5 > 3.45。

错比较 985 和 1024，看到 9 比 1 大，就判断 985 大。

为什么错整数比大小先看位数。1024 是四位数，最高位是千位，985 只是三位数，千位上的一个就压过百位上的一切。

正确985 < 1024。

错认为 1/4 > 1/3，理由是 4 比 3 大。

为什么错分子相同时，分母越大表示整体被切得越细，每一份越小。四分之一是切成 4 份取 1 份，三分之一是切成 3 份取 1 份，后者每份更大。

正确1/4 < 1/3。

错比较 2/3 和 3/5，看到 3 比 2 大、5 比 3 大，就判定 3/5 大。

为什么错分子分母分别在变大，说不清整体到底变大还是变小。必须通分或化成小数才能比。

正确通分得 10/15 与 9/15，所以 2/3 > 3/5。

错把 3/5 通分成 3/40，只把分母乘了 8。

为什么错分母乘 8 而分子不变，分数就被缩小成原来的八分之一，大小已经改了。

正确3/5 = 3 × 8/5 × 8 = 24/40。

错认为 -5 > -2，理由是 5 比 2 大。

为什么错负号把方向掉了个头。-5 在数轴上位于 -2 的左边，离 0 更远，所以它更小。两个数离 0 的远近关系在这里正好要反过来读。

正确-5 < -2，-5℃ 比 -2℃ 更冷。

错比较 -1/2 和 -1/3，因为 1/2 > 1/3，就判定 -1/2 > -1/3。

为什么错加上负号以后，两个数都跑到 0 的左边，原来「谁大」的结论要整个翻过来：负号后面的数大的那个更靠左，也就更小。

正确-1/2 < -1/3。

错比较 -5 和 3 时，看到 5 比 3 大，就判断 -5 > 3。

为什么错-5 是负数，在 0 的左边；3 是正数，在 0 的右边。正数一定大于负数，跟数字本身谁大没有关系。

正确-5 < 3。

直观理解

比大小像在台阶上比身高：先看谁站在更高的台阶（位数、整数部分），站得高的直接赢；站在同一级台阶上，再从头顶往下一点点比。小数补 0 就是把两个人的鞋底垫平，让大家站在同一个平面上，比出来才不会歪。 （分数比较大小） 分数比大小像分蛋糕：分母是「切成几刀」，分子是「拿了几块」。切得越碎，同样拿一块就越小，所以分母大的分数不一定大。真要比出高低，要么把两块蛋糕切成同样多的份数再数块，要么干脆称一称各有多重，这就是通分和化小数。 （正负数比较大小） 负数像电梯里的地下楼层按钮：-1 层就在地面下一层，-3 层还要更往下。楼层数字越大，说明离地面越远、位置越低。比「谁高」的时候，-1 层当然比 -3 层高。地面上和地面下一起排，地面上的永远在上面。

整数比大小，先看几位好；位数相同的，高位先开炮。 小数比大小，整数部分瞧；相同往下比，缺位零来补。 位数多不算大，数位对齐才可靠。 百分位、千分位，一位一位别乱了。 （分数比较大小） 同分母，比分子，份数多的它就大。 同分子，比分母，母大反而数变小。 都不同，别乱猜，通分或者化小数。 通分记牢一句话：分母乘几子也乘。 （正负数比较大小） 数轴一条线，右大左小记心间。 正数大于零，零比负数全都前。 两个负数比大小，负号后面数再看： 那个数越大它越小，零下五度冷过二。
