说明

数数的时候，我们不是一个一个数到一万的，而是十个十个地打包：10 个一是十，10 个十是百，10 个百是千，10 个千是万。每满十个就换一个更大的单位，这叫十进制。

每个单位在自己的位置上排队，这些位置叫数位。从右边起依次是个位、十位、百位、千位、万位。3 写在千位上就是 3 个千，写在个位上就是 3 个一——同一个数字，站的位置不同，大小差了一千倍。

写数从高位写起，一位一位往右写。哪一位上一个单位也没有，就在那一位写 0 占位。三千零五写作 3005：千位写 3，百位、十位没有就写 0、0，个位写 5。

读数也是从高位读起，千位是几就读「几千」，百位是几就读「几百」…… 但有两条特殊规则：末尾的 0 都不读（3500 读作三千五百）；中间不管连续几个 0，都只读一个「零」（3005 读作三千零五，4007 读作四千零七）。

说数的组成时，就看每个数字站在哪一位上：3005 是由 3 个千和 5 个一组成的；3500 是由 3 个千和 5 个百组成的。这两个数读起来只差一个「零」，大小却差了四百九十五。

使用场景

图书馆的书号：一本书编号 3005，要读成「三千零五」，写作 3005，中间两个 0 一个都不能少。

全校人数、运动会入场人数：1240 人读作一千二百四十，末尾的 0 不用读出来。

储蓄罐里的钱数：存到 2070 元，读作二千零七十——中间的 0 要读，末尾的 0 不读。

体育馆、影院的座位数：5008 个座位读作五千零八。

商品价格、楼层编号、门牌号：都要先读准，才不会找错地方、买错东西。

注意点

0 一定要占位。二千零五写作 2005，写成 205 就成了二百零五——数字没变，位置全乱了。

中间有 0 必须读出来。3005 不能读成「三千五」，三千五是 3500。那个「零」是在提醒听的人：百位和十位都跳过去了。

末尾的 0 一个都不读。3500 读三千五百，1240 读一千二百四十，别画蛇添足读成「三千五百零零」。

中间连续几个 0 也只读一个零。4007 读四千零七，不是「四千零零七」。

读数和写数都要从高位开始。先找最大的一位，一位一位往下走，不要从个位倒着读。

为什么是这样

算理推导

  1. 先数一数小方块：一个一个地数，数到 10 个一，就捆成一条，叫「十」；一条一条地数，数到 10 条，就拼成一板，叫「百」；一板一板地数，数到 10 板，就垛成一大块，叫「千」；10 大块就是「万」。每满十个就换一个更大的单位——这就是十进制，也是我们只用一个 0~9 的数字就能写出所有数的原因。

  2. 既然一个数字的值由它站的位置决定，位置就必须写清楚。3、5 两个数字，写成 35 是三十五，写成 3500 是三千五百——区别全在中间那两个「没有」的位上。所以0 的作用不是「表示没有」，而是「占住位置，不让后面的数字往前挪」。没写 0，3 就会从千位滑到十位、5 从百位滑到个位，整个数就变了。

  3. 为什么末尾的 0 不读？读数是在报「每一位上有几个单位」。3500 里有 3 个千、5 个百，个位十位都是空的——既然空着，就没东西可报，说「三千五百」已经把话说完了。非要读成「三千五百零零」，等于在报两个不存在的单位，听着反而糊涂。

  4. 为什么中间的 0 一定要读，而且只读一个？因为中间的空位是断层，必须提醒。听到「三千零五」，你就知道千位之后直接跳到个位，百位和十位是空的。至于空了两位还是一位，听到的结果是一样的（都是跳过去），所以连续几个 0 只读一个「零」就够了，说「零零」并不会多传递信息。

  5. 现在看 3005 为什么不能读成「三千五」。在中文里「三千五」是「三千五百」的省略说法，5 会落到百位上；而 3005 的 5 在个位。两者相差 3500 - 3005 = 495。中间那一声「零」，就是防止 5 滑到百位上去的挡板。

  6. 最后看组成：把每个数字和它的数位连起来读一遍——3005 是 3 个千、0 个百、0 个十、5 个一，也就是 3000 + 5；3500 是 3 个千、5 个百，也就是 3000 + 500。会拆会拼，才算真的认识这个数。

动手实验

用 4 张数字卡片「3、0、0、5」，和同桌一起摆四位数，看能摆出几种：3500、3050、3005、5300、5030、5003（0 不能摆在最高位，所以 0350 这类不算）。每摆出一个就大声读一遍，另一个人把它写下来，然后交换检查。你会发现：两个 0 挨在一起的（3005、5003）读出来只有一个「零」，0 在末尾的（3500、5300）一个「零」都不读。再用计数器拨一拨 3005 和 3500，看看珠子一颗落在个位、一颗落在百位，数就差了这么多。

按场景的例题

例 1（场景：校园生活）　图书馆给新书编号

一本绘本的编号是 3005，另一本是 3500。这两个数分别怎么读？3005 是由几个千和几个一组成的？

解：3005：千位是 3，百位和十位都是 0，个位是 5。中间连续两个 0 只读一个「零」，读作三千零五，由 3 个千和 5 个一组成。3500：千位 3、百位 5，末尾两个 0 不读，读作三千五百，由 3 个千和 5 个百组成。

答：3005 读作三千零五（3 个千和 5 个一）；3500 读作三千五百（3 个千和 5 个百）。

例 2（场景：计量与估算）　运动会统计入场人数

学校运动会，上午入场 1240 人，下午入场 1008 人。这两个数怎么读？

解：1240：千位 1、百位 2、十位 4、个位 0，末尾的 0 不读，读作一千二百四十。1008：千位 1，百位和十位都是 0，个位 8，中间连续两个 0 只读一个零，读作一千零八。

答：1240 读作一千二百四十；1008 读作一千零八。

例 3（场景：金融理财）　数一数储蓄罐里的存钱数

小美的储蓄罐里一共有 2070 元。这个数怎么读？如果她又存入 9 张 100 元，一共是多少元，怎么读？

解：2070：千位 2、百位 0、十位 7、个位 0，中间的 0 要读、末尾的 0 不读，读作二千零七十。再存 9 张 100 元是 900 元，2070 + 900 = 2970，读作二千九百七十。

答：2070 读作二千零七十；再存 900 元后是 2970，读作二千九百七十。

例 4（场景：工程建造）　新建的体育馆统计座位数

新建的体育馆有五千零八个座位，这个数怎么写？它是由几个千和几个一组成的？

解：从高位写起：五千 → 千位写 5；百位、十位一个单位也没有 → 都写 0 占位；个位 8。写作 5008。它由 5 个千和 8 个一组成。要检查一下：中间两个 0 只读一个零，读回来正是「五千零八」。

答：写作 5008，由 5 个千和 8 个一组成。

常用推论

  • 十进制进率：10 个一是十，10 个十是百，10 个百是千，10 个千是万。相邻两个计数单位之间的进率都是 10。

  • 数位顺序（从右起）：个位、十位、百位、千位、万位；同一个数字所在的数位越靠左，表示的数越大。

  • 读数规则：从高位读起；末尾的 0 都不读；中间有一个 0 或连续几个 0，都只读一个「零」。

  • 写数规则：从高位写起，哪一位上一个单位也没有，就在那一位写 0 占位。

  • 数的组成：一个数可以拆成各数位上的数与计数单位相乘再相加，如 3500 = 3000 + 500、3005 = 3000 + 5。

  • 最大的四位数是 9999，再添 1 就是最小的五位数 10000（一万）。

易错点

错3005 读成「三千五」。

为什么错「三千五」是三千五百（3500）的省略说法，5 落在百位上。3005 的 5 在个位，中间隔了百位和十位两个空位，必须用「零」提醒。

正确读作三千零五。两个数相差 3500 - 3005 = 495，一个「零」差了四百九十五。

错3500 读成「三千五百零零」，1240 读成「一千二百四十零」。

为什么错末尾的 0 表示这一位上一个单位也没有，没有东西可报，读出来是多余的。

正确3500 读三千五百，1240 读一千二百四十。

错「二千零五」写成 205。

为什么错漏了占位的 0。写成 205，2 从千位降到了百位，5 仍在个位——丢掉的是百位和十位上的 0，整个数变成二百零五。

正确写作 2005：千位 2，百位、十位写 0 占位，个位 5。

错4007 读成「四千零零七」。

为什么错中间连续两个 0 只需要报一次「零」。报两次并不会让人多听出一位。

正确读作四千零七。同理 1008 读一千零八，不是「一千零零八」。

直观理解

把数位想成一排固定的座位，从左到右挂着「万、千、百、十、个」的牌子。数字是乘客，3 坐在千位这个座位上就是 3 个千，坐在个位上就是 3 个一——同一个人换个座位，身份完全变了。座位空着没人坐，就挂个「0」的牌子占住，否则后面的人会一个个往前挪，3005 就变成 35 了。读数像报号码：中间哪几个座位空着，报一声「零」提醒对方跳过；最后几个座位空着就不用报，因为号码已经报完了。

十个一是十，十个十是百，十个百是千，十个千是万。末尾的零都不读，中间的零只读一个；哪一位上一个也没有，一定写零来占位。
