说明

我们熟悉的 1、2、3、0.5、3/4 这些比 0 大的数，都叫正数。在正数前面加上一个「-」号，就得到负数，比如 -1、-0.5、-3/4。

0 既不是正数，也不是负数。它是正数和负数的分界点，既不在正数那边，也不在负数那边。这一条是考试里最常考、也最常被忽略的一条。

正数前面的「+」号通常可以省略：+3 就写成 3。但负数前面的「-」号绝对不能省，因为一旦省掉，-3 就变成了 3，意思完全反过来。

使用场景

气温：天气预报说「明天 -5\ ℃」，意思是比 0 摄氏度低 5 度。冬天在北方，这个数再常见不过。

楼层：商场地下一层记作 -1 层，地下二层记作 -2 层。电梯按钮上的「-1」「-2」就是负数。

收支：微信账单里收入 200 元记作 +200，支出 200 元记作 -200。两个数大小一样、方向相反，正好抵消。

海拔：吐鲁番盆地最低处海拔 -154 米，表示它比海平面低 154 米。

水位与涨跌：股票跌 3 个点记作 -3，河水水位下降 0.2 米记作 -0.2。

注意点

0 属于「非正非负」，不是正数也不是负数。看到「0 是最小的正数」这种说法，一律判错。

负号不能省。写 -7 时那个小横杠必须写清楚，尤其是在填空和口算里。

带分数和小数也有负数：-0.5、-11/2 都是负数，不要以为只有整数才有负数。

不要把「-」读成「减」。在 -3 里它是负号，表示这个数的性质；在 5-3 里它是减号，表示一种运算。同一个符号，两种身份。

为什么是这样

算理推导

  1. 先看一个麻烦：今天收入 200 元，明天支出 200 元。如果只用正数，这两件事都写成「200」，完全分不清谁进谁出。

  2. 再看另一个：零上 5 度和零下 5 度，如果都写成「5」，也没法区分。

  3. 人们发现，生活里有很多量是成对出现、方向相反的——进与出、升与降、上与下、赢与输。要同时记录它们，光有正数不够。

  4. 于是约定：把其中一种方向定为正，另一种就记为负。这样一个数的符号就代替了一整句话：写 -200，等于写了「支出 200 元」五个字。

  5. 这个「正」是人为约定的。把收入定为正、支出定为负是习惯；反过来把支出定为正也完全可以，只要前后一致。真正重要的是两个数符号相反。

  6. 至于 0，它是「刚好没有变化」的那个状态：不进不出、不升不降。它两边都不沾，所以既不是正数也不是负数。

动手实验

拿一张纸画一条横线，中间点一个 0，右边依次写 1、2、3，左边对称地写 -1、-2、-3。现在把今天的真实气温标上去（比如 -2），再标出室内温度（比如 22）。你会直观地看到：0 就在中间，把两个数分成两拨。再试一次：把 -0.5 标进去，它落在 0 和 -1 正中间——说明小数、分数也在这条线上，负数不是整数专属。

按场景的例题

例 1（场景：自然现象）　看天气预报安排出行

哈尔滨某天最高气温 -3\ ℃，最低气温 -12\ ℃。这一天的温差是多少摄氏度？

解：温差 = 最高温 − 最低温 = -3 - (-12) = -3 + 12 = 9。减去一个负数，等于加上它的相反数。

答：9 摄氏度。

例 2（场景：金融理财）　记录一个月的零花钱流水

小明 3 月收入压岁钱 +300 元，买书支出 -85 元，买文具支出 -42 元，月底结余多少元？

解：把带符号的数加起来：300 + (-85) + (-42) = 300 - 85 - 42 = 173。

答：结余 173 元。

例 3（场景：上学日常）　用正负数记录电梯楼层

小红从 5 楼坐电梯到地下 2 层的车库，再从车库回到 1 楼。如果把向上记作正、向下记作负，这两段分别记作什么？

解：从 5 楼到 -2 层，一共下降 7 层，记作 -7；从 -2 层回到 1 层，上升 3 层，记作 +3。

答：第一段 -7，第二段 +3（或 3）。

例 4（场景：行程出行）　判断海拔高低

甲地海拔 +860 米，乙地海拔 -154 米，两地相差多少米？

解：一个在 0 之上 860，一个在 0 之下 154，相差 860 + 154 = 1014。

答：1014 米。

常用推论

  • 相反数：符号不同、绝对值相同的两个数互为相反数，如 +5 与 -5。它们加起来正好是 0。

  • 用正负抵消算总和：把带符号的数直接相加，正的部分和负的部分会自动抵消，结果就是净变化量。

  • 0 的相反数是 0：它既不是正数也不是负数，自己的反面还是自己。

易错点

错认为 0 是最小的正数，或者认为 0 是负数。

为什么错0 是正数与负数的分界点，哪一边都不属于。这是定义，不是习惯。

正确0 既不是正数也不是负数。最小的正整数是 1，最大的负整数是 -1。

错把 -1/2、-0.3 说成「不是负数」，理由是「负数都是整数」。

为什么错负数只看符号，不看它是整数、小数还是分数。只要小于 0，就是负数。

正确-1/2 和 -0.3 都是负数。

错温差算成 -3 + (-12) = -15。

为什么错温差是「高减去低」，-3 反而比 -12 高。把两个负数直接相加，算出来的是别的东西。

正确-3 - (-12) = 9，温差是 9 摄氏度。

错写负数时漏掉负号，把 -7 写成 7。

为什么错负号是负数的一部分，漏掉后数的符号就反了，意思完全改变。

正确写成 -7，并检查那个小横杠是否清晰可见。

直观理解

把数想成一条东西向的马路，0 是十字路口。正数往东走，负数往西走，符号告诉你方向，数字告诉你走了多远。0 就站在路口不动——它既不往东也不往西，所以两边都不算。负数并不「比没有还少」，它只是「往另一个方向的那么多」。

零上零下有正负，收入支出两相符。零在中间分界线，非正非负要记住。负号小横别漏写，一漏方向就反了路。
