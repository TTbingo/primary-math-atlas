说明

有些题用算术方法做起来很别扭。比如：「果园里桃树比梨树多 40 棵，桃树是梨树的 3 倍，梨树有多少棵？」要求梨树，得先自己想明白「多出来的 40 棵正好对应 2 倍」，然后才算 40 ÷ 2 = 20。这个「2 倍」题目里根本没写，得靠脑子补出来——这一步想不到，题就卡住了。

方程换了一条路：不知道梨树有多少，就先给它起个名字，设梨树有 x 棵。题目第一句说桃树是梨树的 3 倍，那桃树就是 3x 棵；第二句说桃树比梨树多 40 棵，那就写 3x - x = 40。题目说一句，式子写一句，中间不需要任何「倒推」。

所以列方程解应用题有一套固定的五个步骤：一审题找等量关系、二设未知数、三列方程、四解方程、五检验作答。真正决定成败的是第一步和第三步，第四步只是按等式性质机械地走，第五步是收尾。

设谁为 x，有两条原则。第一条：设较小的量。上面那题设梨树为 x，桃树就是 3x，两样都是整数倍；要是设桃树为 x，梨树就成了 x ÷ 3，分数一出来，算起来就别扭。第二条：设一倍量。倍数关系里那个「1 倍」的量是基准，别的量都是它的整数倍，拿基准当 x，式子最干净。题目最后问的如果不是 x，求完 x 再算一步就行。

等量关系从哪里找？就藏在已经学过的数量关系里：总价 = 单价 × 数量，路程 = 速度 × 时间，部分 + 部分 = 总量，原有多少 - 用去多少 = 还剩多少，「甲比乙多几」「甲是乙的几倍」也都是现成的等量关系。审题时先用一句大白话把它说出来，再动笔列式，错的机会就少一大半。

同一道题，两种解法摆在一起看最清楚。果园那题：算术解法是 (3 - 1) 这一步最难想，得先看穿「40 棵对应 2 倍」；方程解法是 3x - x = 40，两个 x 一减自然变成 2x = 40，x = 20。算术法要倒着想，方程法顺着题意写——题目怎么说，式子就怎么摆，难度从「想」转移到了「写」。

使用场景

农业生产：果园里两种果树的棵数、两个大棚的产量，谁比谁多几、谁是谁的几倍，都能直接写成方程。

购物消费：买几种文具或体育器材一共花了多少元，已知其中一种的单价，求另一种的单价。

行程出行：共享单车从多的地方调一批到少的地方，调完两边一样多；或者两车相向而行、几小时相遇。

校园生活：两个社团一共多少人、书法社比航模社多几人，求各有多少人。

工程建造：一条路已经修了多少米、剩下的比修好的多多少，求全长。

注意点

「设」必须写出来，并且写清单位：「设梨树有 x 棵」。方程里只写数，x 后面不带单位。

列式前先用一句话说出等量关系。说不出来就先别写方程，否则列出来的式子自己都不知道在说什么。

方程两边的单位要一致。左边算的是棵数，右边也必须是棵数；一边元一边角，等号两边就不相等了。

设小不设大、设一倍不设几倍。这样能避开分数，省掉一大堆麻烦。

求出 x 不等于做完了。要检验，还要看清问题问的是哪个量，答句别答错对象。

不要一上来就写算式。先审题、先找关系，比急着动笔重要得多。

为什么是这样

算理推导

  1. 先看算术法为什么难：它要求「从答案往回走」。要求梨树，就得先知道「40 棵对应几倍」，而这个「几倍」题目没有直接给，得用 3 - 1 自己减出来。这一步靠的是灵光一现，想不到就再也走不下去。

  2. 方程法反过来「顺着题意往前走」：不知道梨树，就先叫它 x。题目说桃树是梨树的 3 倍，桃树就是 3x；题目说桃树比梨树多 40 棵，就写 3x - x = 40。每读一句，就落一笔，不需要提前看穿什么。

  3. 方程凭什么能顺着写？因为 x 和已知的数在式子里地位相同，都能参加加减乘除。算术法里未知数不能进算式，只能孤零零待在等号右边等着被算出来，所以每一步都得倒推。

  4. 为什么设较小的量：设梨树为 x，桃树是 3x，式子里只有一个 x。要是设桃树为 x，梨树就得写成 x ÷ 3，分数一出现，两边同乘 3 才能往下走，白白多了两道坎。

  5. 为什么设一倍量：桃树是梨树的 3 倍，「梨树」就是这个关系里的 1 倍量。以它为 x，桃树就是干净的 3x；以 3 倍量为 x，1 倍量必然带分数。基准选对了，式子自己就简单。

  6. 最后一步解方程反而最不需要动脑：3x - x 就是 3 个 x 减去 1 个 x，剩 2 个 x，得 2x = 40，两边同时除以 2，x = 20。难点在列，不在解——这就是方程把难题变简单的地方。

动手实验

拿果园这道题，用两种方法各做一遍，并排写在纸上。算术法：40 ÷ (3 - 1) = 20，只有一行，但旁边要用箭头标出「40 对应 2 倍」这个关键想法。方程法：设梨树 x 棵，3x - x = 40，2x = 40，x = 20，四行，可每一行都是照着题目抄下来的。写完数一数：算术法 1 行算式 + 1 个必须想通的念头；方程法 4 行，0 个需要灵感的念头。再换一道「两数之和是 96、相差 12」的题重做一遍，看是不是同样的感觉。

按场景的例题

例 1（场景：农业生产）　果园里的桃树和梨树

果园里桃树比梨树多 40 棵，桃树是梨树的 3 倍。梨树、桃树各有多少棵？

解：设梨树有 x 棵，则桃树有 3x 棵。等量关系是「桃树 - 梨树 = 40」，列方程 3x - x = 40，得 2x = 40，x = 20；桃树 3 × 20 = 60。检验：60 - 20 = 40，60 ÷ 20 = 3，两条都对。

答：梨树 20 棵，桃树 60 棵。

例 2（场景：购物消费）　给班级买体育器材

学校买 3 个排球和 2 个篮球，一共 260 元。篮球每个 70 元，排球每个多少元？

解：设排球每个 x 元。等量关系是「排球的钱 + 篮球的钱 = 总钱数」，列方程 3x + 2 × 70 = 260，即 3x + 140 = 260。两边同时减 140，得 3x = 120；两边同时除以 3，得 x = 40。检验：3 × 40 + 140 = 260。

答：排球每个 40 元。

例 3（场景：行程出行）　共享单车的站点调度

A 站点的单车数是 B 站点的 4 倍。从 A 站点调 30 辆到 B 站点后，两个站点的车一样多。B 站点原来有多少辆？

解：设 B 站点原有 x 辆，则 A 站点原有 4x 辆。调完后 A 剩 4x - 30 辆，B 有 x + 30 辆，等量关系是「调完后两边一样多」，列方程 4x - 30 = x + 30。两边同时减 x，得 3x - 30 = 30；两边同时加 30，得 3x = 60；两边同时除以 3，得 x = 20，A 站点原有 4 × 20 = 80 辆。检验：80 - 30 = 50，20 + 30 = 50，两边相等。

答：B 站点原有 20 辆，A 站点原有 80 辆。

例 4（场景：校园生活）　两个社团的人数

书法社和航模社一共有 96 人，书法社比航模社多 12 人。两个社各有多少人？

解：设航模社有 x 人（较小的量），则书法社有 (x + 12) 人。等量关系是「两社人数之和 = 96」，列方程 x + (x + 12) = 96，得 2x + 12 = 96。两边同时减 12，得 2x = 84；两边同时除以 2，得 x = 42，书法社 42 + 12 = 54 人。检验：42 + 54 = 96，54 - 42 = 12。

答：航模社 42 人，书法社 54 人。

常用推论

  • 列方程解应用题的五个步骤：审题找等量关系、设未知数、列方程、解方程、检验并作答。

  • 设未知数优先设较小的量或一倍量，可以避免式子里出现分数。

  • 常用的等量关系：总价 = 单价 × 数量；路程 = 速度 × 时间；部分 + 部分 = 总量；原有的 - 用去的 = 剩下的。

  • 形如 ax ± bx = c 的方程，先用乘法分配律把左边合并成 (a ± b)x = c，再两边同时除以 (a ± b)。

易错点

错「桃树是梨树的 3 倍，桃树比梨树多 40 棵」，设桃树有 x 棵，把梨树写成 x ÷ 3。

为什么错设了较大的量，另一个量就只能用除法表示，式子里出现分数，每一步都多一道坎。

正确设梨树有 x 棵（较小的量、一倍量），桃树就是 3x 棵，方程是 3x - x = 40。

错把「桃树比梨树多 40 棵」列成 3x = 40。

为什么错「多 40 棵」说的是两个量之间的差，不是桃树本身的棵数。3x 表示桃树，它不等于 40。

正确差要写成减法：3x - x = 40，解得 x = 20。

错在方程里带单位，写成 3x - x = 40（棵）。

为什么错方程里参与运算的是数，单位只在「设」和「答」里出现。把单位塞进算式，读起来就成了「40 棵」这个整体在参与运算。

正确方程写 3x - x = 40；单位写在设句「设梨树有 x 棵」和答句里。

错算出 x = 20 就写「答：桃树有 20 棵」。

为什么错x 设的是梨树。求出 x 只是走完一半，问题问的那个量可能还要再算一步。

正确答：梨树 20 棵，桃树 3 × 20 = 60 棵。

直观理解

算术法像倒着走迷宫：得先在心里找到出口，再一步步退回来，中间哪一步想岔了就出不来。方程法像照着说明书装家具：不知道的零件先贴个标签 x，说明书上说「A 是 B 的 3 倍」，就写 3x；说「A 比 B 多 40」，就写 3x - x = 40。一句一句照做，最后拧紧螺丝（解方程），东西自然装好。

列方程，先找等量关系；不知的量设成 x，题目咋说就咋记。设小不设大，设一倍不设几倍；解完代回验一验，答句对准问的人。
