整数和小数比较大小

数与代数比较大小课标：掌握课标必达

整数先比位数，位数相同从最高位逐位比；小数先比整数部分，再比十分位、百分位，缺位补 0 不错位。

说明

比较两个数的大小，用三个符号：大于号 >、小于号 <、等号 =。符号的开口永远朝着大的那个数，尖头朝着小的那个数，所以 5 > 3、3 < 5 说的是同一件事，只是从不同方向读。

整数比大小，先看位数。 位数不同，位数多的那个大：四位数一定比三位数大，因为四位数的最高位是千位，千位上的一个就顶十个百。位数相同，就从最高位起一位一位往下比，谁先大谁就大，后面的位不用再看。

小数比大小，先比整数部分，再比小数部分。 整数部分谁大谁就大；整数部分相同，就比十分位；十分位相同，再比百分位，一位一位往下走。走的顺序和整数完全一样，只是数位往右延长了。

小数部分的位数常常不一样，这时候先在小数末尾补 0，把位数补齐再比。0.5 补成 0.50，大小一点没变，因为 5 个 0.1 正好就是 50 个 0.01。补齐之后相同数位上下对齐，逐位比较就不会错位。

最要记住的一点：小数比大小不是比谁位数多，也不是比谁数字串长。0.5 只有一位小数，0.45 有两位，可 0.5 更大。比的是相同数位上「有几个这样的计数单位」，不是哪个数写得更长。

使用场景

超市比价：同款牛奶一家 3.5 元、一家 3.45 元，差几毛也要比清楚。

运动会成绩：跳远 3.05 米、3.5 米、2.98 米，谁第一谁第三要排准。

体检数据：身高 1.4 米和 1.45 米看着差不多，一比才知道差半分米。

快递称重：2.5 千克和 2.05 千克的包裹，运费档位可能就不一样。

注意点

要按相同数位比，不是按数字大小比。十分位上的 4 和十分位上的 5 才有可比性，不能拿百分位的 5 去比十分位的 4。

补 0 只能补在末尾。0.5 补成 0.50 大小不变，补成 0.05 就变成原来的十分之一了。

带单位的量先统一单位再比。1.2 米和 95 厘米不能直接比 1.2 和 95，要先把 95 厘米化成 0.95 米。

排顺序时看清要求。从小到大用 < 连，从大到小用 > 连，写反了意思就全错。

为什么是这样

算理推导

  1. 先想清楚整数为什么位数多就大：三位数的最高位是百位，四位数的最高位是千位，而千位上的一个就相当于十个百。高位一旦多出一级，低位写满也追不上。

  2. 位数相同时，从最高位比起：百位分出胜负就停；百位打平，再看十位；十位打平，再看个位。前面的位一旦定了胜负，后面的位再大也翻不了盘。

  3. 小数沿用同一套思路，只是把数位往右延长：整数部分之后是十分位、百分位、千分位，计数单位一个比一个小。所以先比整数部分，再比十分位，再比百分位。

  4. 位数不同容易错位：0.5 的 5 在十分位，0.45 的 4 在十分位、5 在百分位。把小数点对齐、末尾补 0 写成 0.50 与 0.45，相同数位就上下对齐了，逐位一看便知。

  5. 补 0 为什么不变大小？0.5 是 5 个 0.1，而 50 个 0.01 也是 5 个 0.1，所以 0.5 与 0.50 完全相等。补 0 只是换了一种数法，没有改变量。

动手实验

在数位顺序表上把 3.5 和 3.45 写下来，要求小数点上下对齐，空着的格子补 0，写成 3.50 与 3.45。然后画一条数轴，标出 3.4、3.45、3.5、3.6 四个点，看看 3.45 和 3.5 谁在右边。最后把 0.5 与 0.45、2.5 与 2.05 各比一次，验证「位数多不一定大」。

按场景的例题

例 1（场景：购物消费）　两家店买同款牛奶

同款牛奶，甲店 3.5 元一盒，乙店 3.45 元一盒。哪家便宜？便宜多少元？

解：把 3.5 补成 3.50，与 3.45 逐位比：整数部分都是 3，十分位 5 > 4，所以 3.5 > 3.45。差价 3.50 - 3.45 = 0.05 元。

答：乙店便宜，便宜 0.05 元，也就是 5 分钱。

例 2（场景：校园生活）　运动会跳远比赛

三名同学的跳远成绩是 3.05 米、3.5 米、2.98 米。请从远到近排出名次。

解：先看整数部分：2.98 的整数部分是 2，最小，排第三。3.05 与 3.5 整数部分都是 3，比十分位：0 < 5，所以 3.05 < 3.5。

答：3.5 米第一，3.05 米第二，2.98 米第三。

例 3（场景：计量与估算）　体检量身高

小丁身高 1.4 米，小果身高 1.45 米。谁高？高多少厘米？

解：1.4 补成 1.40，与 1.45 比：整数部分同为 1，十分位同为 4，百分位 0 < 5，所以 1.4 < 1.45。差 1.45 - 1.40 = 0.05 米，即 5 厘米。

答：小果高，高 5 厘米。

例 4（场景：物流运输）　寄快递称重

两个包裹分别重 2.5 千克和 2.05 千克。哪个重？重多少千克？

解：2.5 补成 2.50，与 2.05 比：整数部分同为 2，十分位 5 > 0，所以 2.5 > 2.05。差 2.50 - 2.05 = 0.45 千克。

答：2.5 千克的包裹重，重 0.45 千克。

常用推论

  • 整数比大小：位数多的数大；位数相同，从最高位起逐位比较，先分出大小的一方为大。

  • 小数比大小：先比整数部分，整数部分相同再依次比十分位、百分位、千分位。

  • 小数末尾添 0 或去 0，大小不变，所以位数不同时可以先补齐再比。

  • 小数位数的多少不决定大小：0.5 > 0.45，0.9 > 0.888。

  • 两个数比较，若整数部分相差 1 以上，小数部分再长也改变不了结论。

易错点

错认为 0.45 > 0.5，理由是 45 比 5 大。

为什么错这是把小数当成整数在比。小数比的是相同数位上的计数单位个数：0.45 的十分位是 4，0.5 的十分位是 5，十分位一开比就分出胜负，百分位上的 5 根本轮不到发言。

正确把 0.5 补成 0.50，与 0.45 逐位比，十分位 5 > 4，所以 0.5 > 0.45。

错比较 3.5 和 3.45 时，觉得 3.45 的小数位数多，所以 3.45 大。

为什么错位数多只说明写得更细，不代表量更大。补齐成 3.50 与 3.45 后看十分位，5 比 4 大。

正确3.5 > 3.45。

错比较 985 和 1024，看到 9 比 1 大，就判断 985 大。

为什么错整数比大小先看位数。1024 是四位数，最高位是千位，985 只是三位数，千位上的一个就压过百位上的一切。

正确985 < 1024。

直观理解

比大小像在台阶上比身高：先看谁站在更高的台阶（位数、整数部分），站得高的直接赢；站在同一级台阶上，再从头顶往下一点点比。小数补 0 就是把两个人的鞋底垫平，让大家站在同一个平面上，比出来才不会歪。

整数比大小，先看几位好；位数相同的，高位先开炮。 小数比大小，整数部分瞧；相同往下比，缺位零来补。 位数多不算大，数位对齐才可靠。 百分位、千分位，一位一位别乱了。
