说明

用小棒摆三角形：摆 1 个用 3 根，摆 2 个用 6 根，摆 3 个用 9 根……照这样写下去，永远写不完。于是请一个能变的数来站位置，用字母 n 表示摆了几个，那么用的小棒就是 3n 根。n 可以是 1、2、3、10、100，代进去就能算出对应的根数。字母能表示一个变化的数。

字母还能表示数量关系。苹果每千克 a 元，买 b 千克，一共 ab 元——不管单价是 6 元还是 8.5 元，也不管买几千克，这一句话把所有情况都说完了。长方形的面积 S = ab、路程 s = vt、运算律 a + b = b + a，都是用字母把关系一次说清。

写字母式有几条约定：字母与字母相乘，乘号可以写成「·」或者干脆省略，a × b 写成 ab；数与字母相乘，数要写在字母前面，3 × n 写成 3n，不写 n3；1 与字母相乘，1 省略不写，1 × a 就写 a。加号、减号、除号不能省。

最容易混的是 a^2 和 2a：a^2 读作「a 的平方」，表示 a × a，两个 a 相乘；2a 表示 a + a，两个 a 相加。当 a = 3 时，a^2 = 3 × 3 = 9，而 2a = 2 × 3 = 6，差了 3。只有当 a = 2（或 a = 0）时它们碰巧相等，绝不能当成一回事。

字母表示的数还要符合实际情况：a 表示人数，就不能取 0.5；表示长度，就不能取负数。字母式后面带单位时，整个式子要加括号，写成「(a + 28) 岁」，不能写成「a + 28 岁」。

（方程的意义与解方程）

左盘放一个信封和 3 枚硬币，右盘放 11 枚硬币，天平正好平衡。信封里装着几枚？我们还不知道，但它是一个确定的数。数学里把这种「暂时不知道、但确实存在」的数叫未知数，通常用字母 x 表示。把这个平衡关系照原样写下来，就得到 x + 3 = 11。

这样的式子叫方程。判断它是不是方程，只看两个条件，缺一不可：一是必须含有未知数，二是必须是等式——有等号，左右两边相等。x + 3 = 11 两条都占，是方程。

少一条就不行。x + 3 只含未知数，没有等号，它只是一个式子；8 + 5 = 13 是等式，可里头全是已知数，也没有未知数。这两个都不是方程。而 6x = 45、2(x + 11) = 36、x ÷ 4 = 9 都是。

由此得到一条必须记牢的关系：方程一定是等式，等式不一定是方程。把所有等式看成一个大圈，方程就是大圈里的一小块——加上「含未知数」这条额外要求以后剩下的那部分。8 + 5 = 13 在大圈里、在小块外；x + 3 = 11 两处都在。

使方程左右两边相等的未知数的值，叫方程的解；求出这个值的过程，叫解方程。x = 8 是 x + 3 = 11 的解；而「两边同时减 3，得到 x = 8」这一串动作才叫解方程。前者是一个数（名词），后者是一件事（动词），别混着用。

小学解方程只用一件工具——等式的基本性质：等式两边同时加上或减去同一个数，等式仍然成立；两边同时乘同一个数，或同时除以同一个不为 0 的数，等式仍然成立。抓住这一句话，任何一步都能走通，不需要另记一套「移项变号」的口诀。

使用场景

摆图形找规律：用小棒摆正方形，摆 n 个用 3n + 1 根；摆三角形，摆 n 个用 3n 根。规律一句话就写完了。

购物算钱：苹果每千克 a 元，买 b 千克，总价 ab 元；知道 a 和 b 的具体数，代进去就能算。

行程问题：地铁每分钟行 v 米，行 t 分钟，路程 vt 米——公式本身就是字母式。

家庭与年龄：小明今年 a 岁，爸爸比他大 28 岁，爸爸今年 (a + 28) 岁；n 年后爸爸就是 (a + n + 28) 岁。

手机套餐：每月用 x GB 流量，一年就是 12x GB，换成哪个月都能算。

（方程的意义与解方程）

称量与配平：用天平和砝码称出一袋未知重量的豆子，天平平衡的那一刻写出来的就是一个方程。

购物消费：知道总价和数量、要求单价，或者知道总价和单价、要求数量，都可以直接把要求的量设成 x。

校园生活：全班人数、每组人数、组数三者之间，知道两个求第三个，列方程比倒着推更省心。

家庭与年龄：储蓄罐里原有若干元，又存入一些，现在有多少——「原有 + 存入 = 现在」就是等量关系。

计量与估算：已知长方形的周长和长，求宽，周长公式本身就是一个含未知数的等式。

注意点

数要写在字母前面。3 × n 写成 3n，不写 n3——n3 容易被看成「n 加 3」或者一个两位数。

a^2 不是 2a。a^2 = a × a，2a = a + a；a = 5 时，a^2 = 25，2a = 10，差了 15。

只有字母与字母、数与字母之间的乘号能省。3 × 4 不能写成 34，那是把两个数拼成了一个数。

1a 要写成 a。1 和字母相乘，1 省略不写；同理 a × 1 也写 a。

字母的取值要符合实际。a 表示人数只能是自然数，表示长度不能是负数；写「a 岁」的答案时要检查是否合理。

带单位时整个式子加括号。(a + 28) 岁、(3n + 1) 根，别写成 a + 28 岁。

（方程的意义与解方程）

方程必须同时满足两条：含未知数、是等式。看着像方程其实不是的，多半是漏了等号。

每一步都要对两边同时做。只在左边减 8，天平就歪了，等号也就不再成立。

除数不能是 0。等式性质里那句「不为 0 的数」不是废话，两边同除以 0 是没有意义的。

解方程要写「解：」，等号上下对齐。一行一行写清楚，别把几步挤成一个式子，出错时也查不出来。

解完要检验。把求出的值代回原方程，算一算左右两边是不是真的相等；相等才算解对。

未知数后面不带单位。「设每支笔 x 元」，方程里只写 6x = 45，单位留在设句和答句里。

为什么是这样

算理推导

  1. 先看只用数会怎样：摆 1 个三角形写 3，摆 2 个写 6，摆 3 个写 9。每写一个数只管一种情况，想知道摆 100 个用几根，还得重新算。想要一句话管住所有情况，就得请一个「能变的数」来占位——这就是字母。

  2. 字母凭什么能代表那么多数？因为式子里真正稳定的不是那个数，而是数与数之间的关系：不管摆几个，小棒数总是个数的 3 倍。字母 n 只是把「几个」这个位置空出来，3n 把这个关系固定住了。换 n，答案自己跟着变。

  3. 为什么 a^2 和 2a 不一样？a^2 是边长 a 的正方形的面积，是「面」；2a 是两条长 a 的边接起来，是「线」。a = 4 时，正方形面积是 16 平方厘米，两条边接起来只有 8 厘米，一个是平方单位、一个是长度单位，本来就不是一回事。

  4. 为什么数要写在字母前？3n 读作「3 个 n」，正好和乘法「几个几」的说法一致：3 个 n 就是 n + n + n。写成 n3 既不好读，又容易和「n 与 3 组成的两位数」混起来。

  5. 为什么字母能把规律说清？加法交换律写成 a + b = b + a，一个式子对所有数都成立；要是举例子，1 + 2 = 2 + 1、3 + 5 = 5 + 3，举到明年也举不完。字母的厉害之处，就在于用一行字代替了无数行例子。

  6. （方程的意义与解方程）

  7. 把方程想成一台天平：等号就是天平中间那根指针，左边和右边一样重的时候，指针才停在正中间。x + 3 = 11 说的是「一个信封加 3 枚硬币，和 11 枚硬币一样重」。

  8. 天平有一条铁律：两边同时拿走同样重的东西，或者同时放上同样重的东西，天平仍然平衡。左右各拿走 3 枚，左边剩一个信封，右边剩 8 枚，指针还是停在正中——这就是「两边同时减同一个数，等式仍成立」。

  9. 把两边的东西都变成原来的 2 倍（同样的倍数），或者把两边平均分成同样多的份，天平照样平衡。这就是「两边同时乘同一个数」「两边同时除以同一个不为 0 的数」——分成 0 份这件事根本做不到，所以除数不能是 0。

  10. 解方程要做的，就是想办法让 x 一个人留在等号左边，而每一步都不破坏平衡。x + 3 = 11 里 x 被「加了 3」缠住，那就两边同时减 3，把 3 从左边请走；右边 11 减 3 得 8，于是 x = 8。6x = 45 里 x 被「乘了 6」缠住，那就两边同时除以 6。

  11. 所以解方程不是背步骤，而是看清 x 外面裹了什么，就两边一起拆什么。裹了加就同减，裹了减就同加，裹了乘就同除，裹了除就同乘——顺序上先拆加减、再拆乘除，一层层剥到 x 露出来为止。

动手实验

用小棒摆正方形：摆 1 个用 4 根，摆 2 个用 7 根，摆 3 个用 10 根。把个数和根数填进表格，看每次多几根——每多一个正方形，只多 3 根（第一条边共用）。于是 n 个正方形要 3n + 1 根。用 n = 4 验算得 13 根，用 n = 10 验算得 31 根，再实际摆一摆数一数，对上了就说明这个字母式靠得住。 （方程的意义与解方程） 找一台天平（或自制的衣架天平）和一把硬币。左盘放一个不透明信封加 3 枚硬币，右盘放 11 枚，调到平衡，把这件事记成 x + 3 = 11。然后左右两盘各拿走 3 枚，看指针是否还在正中；此时左盘只剩信封，右盘剩 8 枚，于是 x = 8。剪开信封数一数，正好 8 枚。再试一次 2x = 14：左盘放两个一模一样的信封，右盘放 14 枚；把两盘各自平均分成两堆，一堆是一个信封、另一堆是 7 枚，得 x = 7。

按场景的例题

例 1（场景：上学日常）　数学活动课上摆小棒

用小棒摆正方形（每个正方形共用一条边），摆 n 个正方形需要多少根小棒？摆 8 个呢？

解：摆 1 个用 4 根，摆 2 个用 7 根，摆 3 个用 10 根：每多摆一个正方形只多 3 根（有一条边共用），所以是 3n + 1 根。当 n = 8 时，3 × 8 + 1 = 25。

答：(3n + 1) 根；摆 8 个要 25 根。

例 2（场景：购物消费）　水果店买苹果

苹果每千克 a 元，买 2.5 千克要付多少元？当 a = 8 时，一共多少元？

解：总价 = 单价 × 数量 = a × 2.5 = 2.5a（元）。当 a = 8 时，2.5 × 8 = 20。

答：2.5a 元；a = 8 时是 20 元。

例 3（场景：家庭与年龄）　家里的年龄问题

小明今年 a 岁，爸爸比他大 28 岁。爸爸今年多少岁？当 a = 11 时呢？

解：爸爸的年龄 = a + 28，写作 (a + 28) 岁。当 a = 11 时，11 + 28 = 39。

答：(a + 28) 岁；小明 11 岁时爸爸 39 岁。

例 4（场景：行程出行）　地铁的行驶路程

地铁每分钟行 v 米，行 8 分钟能行多少米？当 v = 600 时呢？

解：路程 = 速度 × 时间 = v × 8 = 8v（米）。当 v = 600 时，8 × 600 = 4800。

答：8v 米；v = 600 时是 4800 米。

例 5（场景：农业生产）　文具店买同样的中性笔

买 6 支同样的中性笔一共 45 元，每支多少元？列方程解答。

解：设每支 x 元。6 支就是 6x 元，等于 45 元，列方程 6x = 45。两边同时除以 6，得 x = 7.5。检验：6 × 7.5 = 45，左右相等。

答：每支 7.5 元。

例 6（场景：校园生活）　全班同学分组做实验

六(1)班 42 人分组做实验，每组 6 人，正好分完。可以分成几组？列方程解答。

解：设分成 x 组。每组 6 人，x 组一共 6x 人，等于全班 42 人，列方程 6x = 42。两边同时除以 6，得 x = 7。检验：6 × 7 = 42。

答：可以分成 7 组。

例 7（场景：物流运输）　储蓄罐里的零花钱

小杰的储蓄罐里原有一些钱，这周又存入 25 元，现在一共 68 元。原来有多少元？

解：设原来有 x 元。「原有的 + 存入的 = 现在的」，列方程 x + 25 = 68。两边同时减 25，得 x = 43。检验：43 + 25 = 68。

答：原来有 43 元。

例 8（场景：计量与估算）　量长方形花坛的宽

一个长方形花坛的周长是 36 米，长是 11 米，宽是多少米？

解：设宽是 x 米。由周长公式 2 × (\text长 + \text宽) = \text周长，列方程 2(x + 11) = 36。两边同时除以 2，得 x + 11 = 18；两边同时减 11，得 x = 7。检验：2 × (11 + 7) = 36。

答：宽是 7 米。

常用推论

  • 长方形的面积 S = ab、周长 C = 2(a + b)；正方形的面积 S = a^2、周长 C = 4a——公式都是字母式。

  • 运算律的字母式：a + b = b + a，(a + b) + c = a + (b + c)，ab = ba，(a + b)c = ac + bc。

  • 总价 = 单价 × 数量，可写成总价 = ab；路程 = 速度 × 时间，可写成 s = vt。

  • 同一个字母在同一个式子里表示相同的数，不同字母可以表示不同的数；字母取不同的值，式子的结果就跟着变。

  • 等式的基本性质：两边同时加上或减去同一个数，同时乘同一个数，或同时除以同一个不为 0 的数，等式仍然成立。

  • 方程的解是一个数，解方程是一个过程；把解代回原方程能让左右两边相等，就说明解对了。

  • 形如 x + a = b 的方程，两边同时减 a，得 x = b - a；形如 x - a = b 的，两边同时加 a，得 x = b + a。

  • 形如 ax = b 的方程，两边同时除以 a（a ≠q 0），得 x = b ÷ a；形如 x ÷ a = b 的，两边同时乘 a，得 x = ab。

易错点

错a = 5 时，把 a^2 算成 2 × 5 = 10。

为什么错把「平方」当成了「乘 2」。a^2 是两个 a 相乘，2a 才是两个 a 相加。

正确a^2 = 5 × 5 = 25，2a = 2 × 5 = 10，两者差 15。

错把 3 × n 写成 n3。

为什么错数与字母相乘，数要写在字母前面，这是约定，也符合「3 个 n」的读法；写成 n3 还容易被看成一个两位数。

正确写成 3n，读作「3 个 n」。

错把 3 × 4 也省成 34。

为什么错省略乘号只用在含字母的乘法里。两个数相乘省掉乘号，就变成一个两位数了，意思全变。

正确两个数相乘照写 3 × 4；只有 3 × n 才写成 3n。

错爸爸比小明大 28 岁，小明 a 岁时写成「爸爸 a + 28 岁」。

为什么错整个式子后面带单位时要加括号，否则容易读成「a 加上 28 岁」，把数和单位拆开了。

正确写成「爸爸 (a + 28) 岁」。

错把 x + 3 和 3x 也说成方程。

为什么错它们只含未知数，没有等号，不是等式。方程的两个条件缺一不可，光有未知数不算。

正确加上等号、让两边相等才是方程，如 x + 3 = 11、3x = 12。

错认为「等式就是方程」，说 8 + 5 = 13 是方程。

为什么错方程一定是等式，等式不一定是方程。8 + 5 = 13 里全是已知数，缺了「含未知数」这一条。

正确8 + 5 = 13 只是等式；只有含未知数的等式才是方程。

错解 x + 8 = 20 时，只在左边减 8，写成 x = 20。

为什么错只对一边动手，两边就不相等了，天平立刻歪掉，等号也就失去了意义。

正确两边同时减 8：左边 x + 8 - 8 = x，右边 20 - 8 = 12，得 x = 12。

错解 2x = 10 时，写成「两边同时除以 0」，或者由 0x = 5 推出 x = 5。

为什么错0 不能作除数，两边同除以 0 这件事本身没有意义；0x 永远等于 0，不可能等于 5，这样的方程没有解。

正确2x = 10 两边同时除以 2，得 x = 5；除数必须是 0 以外的数。

错把 x + 8 = 20 写成「移项得 x = 20 + 8」。

为什么错小学阶段解方程的依据是等式的基本性质，不是「移项变号」。跳过两边同时运算这一步，符号极容易搞反。

正确两边同时减 8，得 x = 20 - 8 = 12。

直观理解

字母像一个写着名字的储物盒：盒子上标着 n，里面装几个由你定，今天装 3 个、明天装 100 个都行；3n 就是「三个这样的盒子」。a^2 是边长 a 的一块方布，2a 是两根长 a 的绳子接起来——一块布和一根绳，当然不能混为一谈。 （方程的意义与解方程） 把方程想成一台天平，x 是封在盒子里的砝码，盒子外面裹着几层包装：加了几、乘了几。解方程就是一层层拆包装——外面裹了加就两边一起减，裹了乘就两边一起除。每拆一层，两边同时动手，指针就一直停在正中；包装拆完，盒子里的数自己露出来。

字母站个位，数儿随便换；数字写前头，乘号可不见；a 的平方是自乘，2a 是两个添。 （方程的意义与解方程） 含有未知数，还得是等式；两样都齐全，才叫方程式。两边同加减，天平不偏西；同乘同去除，零要躲开去。

关联知识点

前置

  • 加法、乘法的运算律与减法、除法的性质四年级已经用字母写过乘法运算律，这里是把它讲透
  • 用字母表示数与方程的意义先会用字母表示未知数，才写得出含未知数的等式
  • 除数是一位数与除数是两位数的除法解方程里最常见的一步就是除法，除法算理熟了方程才好解
  • 乘方用字母表示数以后，a^2、a^3 直接就是乘方的写法
  • 数量间的加减关系与倍的关系五上用字母表示数量关系时，「a 的 3 倍」写成 3a，倍的说法在字母式子里继续用
  • 人民币、时、分、秒与年月日后续：钱数写多了会想用符号简写，「每支笔多少元、买几支一共多少元」正是用字母表示数的起点
  • 和差、和倍与差倍问题用字母表示数以后，「小数的 3 倍」写成 3x，和就是 x + 3x = 96，份数关系一眼看清
  • 优化问题与找次品优化的思路在六上列方程解应用题时还会用到：先找关键的那一步
  • 鸡兔同笼学过方程后，设兔为 x 顺着列式，比假设法更不容易把「求出来的量」认错

后续

  • 列方程解应用题列方程解应用题时，数量关系要先用字母写清楚，才找得到等量关系
  • 比的意义、化简与正反比例解出两个量之后再比一比，就走到了比和比例
  • 常用的数学思想和方法用字母把「第几个」和「是多少」一一对上，对应这条思路的起点

常一起考

  • 平行四边形、三角形与梯形的面积S = ah 就是字母式，底和高取不同的值，面积跟着变
  • 常见数量关系（总价、路程）总价、路程这些关系式，正是列方程时要找的等量关系
