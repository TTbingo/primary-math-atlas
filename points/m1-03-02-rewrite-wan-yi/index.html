改写成「万」「亿」作单位

数与代数数的改写与近似数课标：掌握课标必达

整万数去掉末尾 4 个 0 换个「万」字，整亿数去掉 8 个 0 换个「亿」字；改写是等值变形，用等号。

印刷第 20 页　行为动词：掌握

说明

像 3840000000 这样的数，位数一多，读要数半天，写要抄一长串。为了读写方便，人们把整万、整亿的数改写成用「万」或「亿」作单位的数：380000 写成 38 万，读作三十八万，一眼就知道大概多少。

怎么改？从右边起数四位，把末尾 4 个 0 去掉，换成一个「万」字。 380000 末尾正好有 4 个 0，划掉，写成 38 万。要改成「亿」作单位，就从右边起数八位，去掉末尾 8 个 0，换成一个「亿」字：500000000 写成 5 亿。

为什么去掉 4 个 0 就等于「万」？因为 1 万就是 10000。380000 里含有多少个 10000？380000 ÷ 10000 = 38。所以 380000 = 38 万。在十进制里，「除以 10000」就是把小数点向左移 4 位，看起来正好是把末尾 4 个 0 划掉。那些 0 并没有消失，它们换了个名字，被装进了「万」字里。

亿的道理相同：1 亿 = 100000000，而 1 亿又等于 10000 万。所以 3 亿 = 30000 万，改写时千万不能把两个单位的名额弄混。

改写和求近似数是两件事。 改写的对象必须是整万、整亿的数，改完数值一分不差，用等号；384600 末尾不是 4 个 0，不能直接改写成万，只能省略万位后面的尾数，看千位上的 4，得 38 万，数值变了，必须用约等号。

使用场景

统计公报：国土面积 960 万平方千米、常住人口 1287 万人，公报里的数字几乎都用万、亿作单位。

快递年报：一年的业务量 1300 亿件，写成 130000000000 件没人愿意读。

校园藏书：图书馆藏书 12 万册，比写 120000 册更像一句话。

经济数据：一座城市的生产总值 3856 亿元，用亿作单位，位数一下子短了下来。

注意点

先数清末尾有几个 0。末尾不够 4 个 0 的数不是整万数，硬改写会改错大小。

中间的 0 不能动。5060000 只划掉末尾 4 个 0，写成 506 万；中间那个 0 是数位的一部分，掉了就变成 56 万。

单位不能叠着写。「38 万万」「5 亿亿」都不是规范的写法，要么用万，要么用亿，一个数只挑一个单位。

改写完要回头验一验：把 38 万还原成 380000，看位数对不对，这是最省事的自查办法。

为什么是这样

算理推导

  1. 把数位顺序表摆出来：从右往左，个、十、百、千是一级，万、十万、百万、千万是一级，亿、十亿、百亿、千亿又是一级。每四位一级，一级一个名字。

  2. 看 380000：从右数四位是 0000，剩下左边的 38 正好站在万级上。万级上的 38 表示 38 个万，后面的 4 个 0 只负责占住个级的位置。

  3. 所以 380000 就是 38 个万，也就是 38 万。用除法核对：380000 ÷ 10000 = 38，商就是万级上的数，余下的 0 就是被「万」字替掉的部分。

  4. 亿是同样的套路，只是往左多走一级：去掉末尾 8 个 0，剩下的部分就是亿级上的数。因为 1 亿 = 10000 万，两个单位之间还差着 4 个 0。

  5. 判断能不能直接改写，只看一件事：末尾的 0 够不够 4 个（或 8 个）。够，就是整万（整亿）数，可以用等号改写；不够，就只能求近似数，用约等号。

动手实验

在纸上写 380000、5060000、1200000000 三个数，用彩色笔从右往左每四位画一条竖线，先分级再读数。然后把竖线右边的 0 用纸片盖住，看看剩下的数配上「万」或「亿」能不能读通。最后用计算器分别除以 10000 和 100000000，对照商是不是你写下的那个数。

按场景的例题

例 1（场景：计量与估算）　查国土面积

我国陆地面积约 9600000 平方千米，改写成用「万」作单位的数是多少？

解：末尾正好 4 个 0，去掉这 4 个 0，换成「万」：9600000 = 960 万。也可以算 9600000 ÷ 10000 = 960。

答：960 万平方千米。

例 2（场景：物流运输）　看快递业务量年报

某年快递业务量达 132000000000 件，改写成用「亿」作单位的数是多少？

解：末尾有 8 个 0 以上，去掉 8 个 0 换成「亿」：132000000000 = 1320 亿。核对：1320 × 100000000 = 132000000000。

答：1320 亿件。

例 3（场景：校园生活）　统计图书馆藏书

图书馆有图书 120000 册，改写成用「万」作单位是多少册？如果实际是 125600 册，省略万位后面的尾数约是多少册？

解：120000 是整万数，去掉末尾 4 个 0：120000 = 12 万。125600 不是整万数，只能求近似数，看千位上的 5，进一，125600 ≈ 13 万。

答：12 万册；约 13 万册。

例 4（场景：金融理财）　读城市经济数据

某市一年生产总值 385600000000 元，改写成用「亿」作单位的数是多少亿元？

解：末尾有 8 个 0 可去，385600000000 = 3856 亿。检验：3856 亿就是 3856 个亿，也就是 385600000000。

答：3856 亿元。

常用推论

  • 改写成万作单位：去掉末尾 4 个 0，写「万」；改写成亿作单位：去掉末尾 8 个 0，写「亿」。

  • 1 亿 = 10000 万，所以把亿作单位的数换成万作单位，要在这个数后面添 4 个 0。

  • 整万、整亿数改写前后完全相等，用等号；末尾 0 不够的数求近似数，用约等号。

  • 省略万位后面的尾数时看千位，省略亿位后面的尾数时看千万位。

  • 一个数能改写成整万数，末尾至少有 4 个 0；能改写成整亿数，末尾至少有 8 个 0。

易错点

错把 384600 省略万位后面的尾数，写成 384600 = 38 万。

为什么错384600 末尾不够 4 个 0，不是整万数，省略尾数之后数值已经变了，等号就站不住了。

正确384600 ≈ 38 万；改写只对整万数做，例如 380000 = 38 万。

错把 380000 改写成 38 万时，写成 380000 ≈ 38 万。

为什么错改写一个数都没丢，是等值变形，用约等号会让人以为取了近似值。

正确380000 = 38 万。

错把 5 亿改写成用万作单位，写成 5 万。

为什么错亿和万之间差着 10000 倍，改写时要添上 4 个 0，不是把「亿」换成「万」就完事。

正确5 亿 = 50000 万。

直观理解

一长串珠子，每 10000 颗装一小盒，每 10000 个小盒再装一大盒。「万」是那一小盒的名字，「亿」是那一大盒的名字。改写不是把珠子扔掉，只是不再一颗颗数，改口说「几小盒」「几大盒」。所以改写前后，珠子一颗也没少。

末尾四零换个万，末尾八零换个亿。 零不够就求近似，约等号才站得稳。 改写等号值不变，还原一遍最放心。 先分级，再动笔，几位一级数得清。

关联知识点

本知识点指向

  • 四舍五入与近似数对照：改写保持数值不变，求近似数会改动尾数，符号也不一样
  • 亿以内数的认识与读写前置：先会给多位数分级、认识亿级，才数得清末尾有几个 0
  • 估算后续：估算和统计表达里，经常先把大数换成万、亿再算

指向本知识点

  • 多位数的读法与写法递进：会读写之后，接着学改写成「万」「亿」作单位
