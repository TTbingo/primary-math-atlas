因数、倍数、质数、合数

研究一个数能被谁整除。2、5、3 的倍数有特征可循，最大公因数和最小公倍数是约分与通分的底座。

所属模块数与代数
课标学段第三学段（5~6年级）
知识点2 篇
课标要求
共 1 条，点开查看知道 2，3，5 的倍数的特征，了解公倍数和最小公倍数，了解公因数和最大公因数，了解奇数、偶数、质数（或素数）和合数。

知识点

  • 因数、倍数与最大公因数、最小公倍数在非零自然数里，a × b = c 中的 a、b 是 c 的因数，c 是 a、b 的倍数。因数个数有限，倍数个数无限。了解课标必达
  • 2、3、5 的倍数特征与质数、合数2 和 5 的倍数只看个位，3 的倍数要看各位数字之和；按因数个数，自然数分成质数、合数和单独的 1。了解课标必达
