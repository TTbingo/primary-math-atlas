# 新增知识点写作规格（2026-11-05 补充篇目专用）

本文件约束本轮新增的 26 篇。**已有 136 篇不必改**（保持原格式，构建器向后兼容）。

## 1. 与既有篇目的差异

新篇的 `sections.related` 采用**三类结构**，既有篇目是单层 `{id, note}`：

```json
"related": [
  {"id": "m1-01-02-num-1-to-5", "kind": "前置",   "note": "先会数 1~5，才谈得上 6~10"},
  {"id": "m1-06-35-div-table-7-9", "kind": "后续",  "note": "乘法口诀学会了，除法才能倒着求商"},
  {"id": "m2-01-25-plane-shapes",  "kind": "常一起考", "note": "数的认识与图形拼摆在同一道综合题里常出现"}
]
```

`kind` 只能取这三个值，**每类至少 1 条**，每篇 2~4 条。三类的语义判据：

| kind | 判据 | 硬约束 |
|---|---|---|
| 前置 | 学本文之前必须先会的概念/技能 | 目标篇目**必须排在本文之前**（按 modules.json 的 topics 数组顺序）；且是本文结论成立的前提 |
| 后续 | 学完本文之后，接着会用本文成果的内容 | 目标篇目**必须排在本文之后** |
| 常一起考 | 中考/小升初里常与本文出现在同一道题里的 | 可以排在任意位置；多为跨领域对照或同一情境的不同角度 |

**方向性硬约束（最重要）**：
- 「前置」类里出现后学篇目 = 违反年级进度（校验器会拦）。
- 「后续」类里出现前学篇目 = 违反教材顺序（校验器会拦）。
- 若确实需要提前借用后学篇目的名词，必须在该篇的 `textbook_ref.note` 或本篇 `cautions` 里写明「某年级后面才学，这里提前借用」。

## 2. 完整的 JSON 结构

```json
{
  "schema": 1,
  "id": "<与文件名完全一致>",
  "type": "point",
  "module": "m1",
  "topic": "m1-01",
  "title": "<中文标题，6~14 字>",
  "slug": "<英文短名>",
  "summary": "<一句话，30~60 字>",
  "keywords": ["3~7 个检索词"],
  "domain": "<数与代数|图形与几何|统计与概率|综合与实践>",
  "strand": "<数与运算|数量关系|图形的认识与测量|图形的位置与运动|数据分类|数据的收集、整理与表达|随机现象发生的可能性|主题活动|项目学习>",
  "segment": <1|2|3>,
  "standard_ids": ["<从 content/standards.json 里选真实存在的 id，1~3 个>"],
  "verb_level": "<了解|理解|掌握|运用|经历|体验|感悟|探索>",
  "literacy": ["<从 taxonomy.literacy 选 1~3 个>"],
  "scope": "core",
  "prerequisites": ["<前置篇目 id，必须在 modules.json 清单内>"],
  "media": [],
  "sections": { ...十板块... },
  "meta": { "source": "课标2022 ...", "reviewed": true, "updated": "2026-11-05" }
}
```

`sections` 的**十个板块**（键名与顺序都不能改）：

| 键 | 类型 | 硬性要求 |
|---|---|---|
| `explanation` | string[] | ≥3 段，总字数 ≥80。用小学生能听懂的大白话讲「是什么」 |
| `scenarios` | string[] | ≥3 条，总字数 ≥80。每条以场景名开头 |
| `cautions` | string[] | ≥3 条，总字数 ≥60。每条「**要点**+解释」 |
| `why` | object | `{steps: [...≥3 条], experiment: "..."}`。**不许出现「证明/求证/证毕/∵/∴」**。steps 要真做算理拆解，**不能把公式换个说法重述一遍** |
| `examples` | array ≥3 | 每题 `{id, scene, context, question, solution, answer, tags}`。`scene` 只能取 taxonomy.scenes 里的值，**同一篇内不得重复** |
| `inferences` | string[] | ≥2 条 |
| `pitfalls` | array ≥3 | 每条 `{wrong, why, right}` 三字段齐全 |
| `intuition` | string | ≥60 字。一个生活类比，不重复 explanation |
| `rhyme` | string | 顺口溜，没有就写 "" |
| `related` | array 2~4 | **三类结构**（见第 1 节） |

## 3. 禁词与语言纪律

**硬禁词**（出现在 sections 任何位置都会被 build 拦下）：
`证明`、`求证`、`证毕`、`∵`、`∴`、`Q.E.D.`

**模板腔禁词**（人工审）：`综上所述`、`值得注意`、`不难发现`、`众所周知`、`由此可见`、`总而言之`、`不难看出`、`我们知道`、`首先……其次……最后`、`在生活中处处`、`具有重要意义`。

**语言要求**：
- 解释环节全部用小学生能听懂的大白话，不用「已知……求证……」的初中句式。
- 先给具体例子，再抽象出结论。
- 「为什么是这样」要让人读完觉得「哦，原来是这样」，而不是「背下来吧」。
- 易错点要先摆出**具体的错误答案**（如「算成 $4 \\times 2 = 8$」），再说错在哪。

## 4. 公式与符号

- 行内 `$6 \\times 4 = 24$`，块级 `$$S = a \\times b$$`（单独一行）。
- **JSON 里反斜杠必须写成 `\\`**（两个），例如 `"$6 \\times 4$"`。
- 人民币写「元」或 `¥`，**绝不能写 `$5`**（会被校验器拦）。
- 面积写 `$\\text{cm}^2$`。
- **禁止 `\\ + 空格` 的写法**（如 `\\ 5`、`a \\ b`），KaTeX 会报错。要空格就写 `~` 或直接并排。

## 5. 情境改造

例题的 `context` 要用现代、孩子有体感的情境：

| 旧资料原型 | 改成 |
|---|---|
| 甲乙两地、两港轮船 | 两个地铁站 / 高铁站 |
| 好马劣马、解放军追敌 | 删除，改地铁快慢车 / 两人骑车 |
| 服装厂用布、某工厂调度 | 给教室做窗帘 / 手工课分材料 / 图书馆换座位 |
| 拖拉机耕地、油菜籽榨油 | 共享单车调度 / 现代农业口吻 |
| 存款利率 + 利息税 | 「零花钱存入储蓄罐」 |

`scene` 只能从这 13 个里取：
`购物消费`、`农业生产`、`物流运输`、`工程建造`、`行程出行`、`上学日常`、`校园生活`、`绿化照明`、`家庭与年龄`、`饮食与配比`、`金融理财`、`自然现象`、`计量与估算`

## 6. 数值必须验算

**所有例题的数字必须自己算一遍**，答案与 solution 里的算式必须一致。用 `Fraction` 验算分数类，用精确整数验算整数类。写完必须能回答「这道题的答案是多少」。

## 7. 前置与年级进度

- `prerequisites` 填真正的前置篇目 id（必须在 modules.json 清单内）。
- **先学的篇目不得引用后学篇目中未引入的概念**。例如二年级上册的篇目，不能出现「百分数」「小数乘法」「方程」这些后学概念。
- 确实需要提前借用时（例如一年级就要用「倍」），在 `cautions` 里写明「这个说法三年级才正式学，这里先借用一下」。
