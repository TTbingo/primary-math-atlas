## 二、✅ 常用推论总表（可直接写入 `inferences`）

### 2.1 四则运算与常见数量关系

| 公式 | 适用 |
|---|---|
| 加数 + 加数 = 和；和 − 一个加数 = 另一个加数 | 一年级起 |
| 被减数 − 减数 = 差；被减数 − 差 = 减数；差 + 减数 = 被减数 | 一年级起 |
| 因数 × 因数 = 积；积 ÷ 一个因数 = 另一个因数 | 二年级起 |
| 被除数 ÷ 除数 = 商；商 × 除数 = 被除数（除数不为 0） | 二年级起 |
| 商 × 除数 + 余数 = 被除数（**余数 < 除数**） | 二下 |
| 单价 × 数量 = 总价；总价 ÷ 单价 = 数量；总价 ÷ 数量 = 单价 | 二下起 |
| 速度 × 时间 = 路程；路程 ÷ 速度 = 时间；路程 ÷ 时间 = 速度 | 三上起 |
| 总数 ÷ 份数 = 平均数；平均数 × 份数 = 总数 | 四下 |
| 工作效率 × 工作时间 = 工作总量 | 六上（工程问题） |
| 收入 − 支出 = 结余 | 一下（购物街） |

### 2.2 平面图形

| 图形 | 周长 | 面积 | 逆向推论 |
|---|---|---|---|
| 长方形 | C = 2(a + b) | S = ab | a = C ÷ 2 − b |
| 正方形 | C = 4a | S = a² | a = C ÷ 4 |
| 平行四边形 | — | S = ah | a = S ÷ h；h = S ÷ a |
| 三角形 | — | S = ah ÷ 2 | h = 2S ÷ a；a = 2S ÷ h |
| 梯形 | — | S = (a + b)h ÷ 2 | h = 2S ÷ (a + b) |
| 圆 | C = πd = 2πr | S = πr² | d = 2r；r = C ÷ 2π；d = C ÷ π |
| 半圆 | 弧长 + 直径 = πr + 2r | S = πr² ÷ 2 | — |
| 等边三角形 | C = 3a | — | a = C ÷ 3 |

### 2.3 立体图形

| 图形 | 表面积 | 体积 |
|---|---|---|
| 长方体 | S表 = 2(ab + ah + bh) | V = abh = Sh（S 为底面积） |
| 正方体 | S表 = 6a² | V = a³ |
| 圆柱 | S侧 = 2πrh；S表 = S侧 + 2πr² | V = πr²h = Sh |
| 圆锥 | 🔶 不作要求 | **V = (1/3)Sh = (1/3)πr²h** |

推论：
- 长方体（正方体）体积统一式：**V = 底面积 × 高**（柱体通用）
- 棱长总和：长方体 = (长 + 宽 + 高) × 4；正方体 = 棱长 × 12
- **等底等高的圆柱与圆锥：锥 1、差 2、柱 3、和 4**（体积比）
- 等底等体积时，圆锥的高 = 圆柱高的 3 倍

### 2.4 单位换算（进率）

| 类别 | 进率 |
|---|---|
| 长度 | 1 km = 1000 m；1 m = 10 dm = 100 cm = 1000 mm |
| 面积 | 1 km² = 100 ha；**1 ha = 10000 m²**；1 m² = 100 dm²；1 dm² = 100 cm² |
| 体积容积 | 1 m³ = 1000 dm³；1 dm³ = 1000 cm³；1 dm³ = 1 L；1 cm³ = 1 mL；1 L = 1000 mL |
| 质量 | 1 t = 1000 kg；1 kg = 1000 g |
| 人民币 | 1 元 = 10 角；1 角 = 10 分 |
| 时间 | 1 世纪 = 100 年；1 年 = 12 月；1 日 = 24 时；1 时 = 60 分；1 分 = 60 秒 |
| 时间补充 | 大月 31 天（1、3、5、7、8、10、12）；小月 30 天（4、6、9、11）；平年 2 月 28 天、全年 365 天；闰年 2 月 29 天、全年 366 天 |

### 2.5 运算定律与性质

- 加法交换律 a + b = b + a；加法结合律 (a + b) + c = a + (b + c)
- 乘法交换律 a × b = b × a；乘法结合律 (a × b) × c = a × (b × c)
- 乘法分配律 (a + b) × c = ac + bc
- 减法性质 a − b − c = a − (b + c)
- 除法性质 a ÷ b ÷ c = a ÷ (b × c)（b、c 均不为 0）
- 带符号搬家 a + b − c = a − c + b；a × b ÷ c = a ÷ c × b
- **商不变的规律**：被除数和除数同时乘或除以相同的数（0 除外），商不变
- **积不变的规律**：一个因数乘几，另一个因数除以相同的数（0 除外），积不变
- 小数点移动：乘 10、100、1000 → 右移一、二、三位；除以则左移

### 2.6 典型数量关系（仅收课标/教材范围内）

| 题型 | 公式 | 范围 |
|---|---|---|
| 归一 | 总量 ÷ 份数 = 单一量；单一量 × 份数 = 所求量 | ✅ |
| 归总 | 单一量 × 份数 = 总量；总量 ÷ 另一份数 = 另一单一量 | ✅ |
| 和差 | 大数 = (和 + 差) ÷ 2；小数 = (和 − 差) ÷ 2 | ✅ |
| 和倍 | 小数 = 和 ÷ (倍数 + 1)；大数 = 小数 × 倍数 | ✅ |
| 差倍 | 小数 = 差 ÷ (倍数 − 1)；大数 = 小数 × 倍数 | ✅ |
| 相遇 | 相遇时间 = 总路程 ÷ 速度和 | ✅ |
| 追及 | 追及时间 = 追及路程 ÷ 速度差 | ✅ |
| 植树（两端都栽） | 棵数 = 全长 ÷ 株距 + 1 | ✅ |
| 植树（只栽一端 / 封闭） | 棵数 = 全长 ÷ 株距 | ✅ |
| 植树（两端都不栽） | 棵数 = 全长 ÷ 株距 − 1 | ✅ |
| 年龄 | 年龄差不变；几年后 = 年龄差 ÷ (倍数 − 1) − 小的现年龄 | ✅ |
| 鸡兔同笼（假设全是鸡） | 兔 = (总脚数 − 2 × 总头数) ÷ 2 | ✅ |
| 按比例分配 | 某份 = 总量 × 该份占比 | ✅ |
| 比例尺 | 图上距离 : 实际距离 = 比例尺 | ✅ |
| 折扣 | 售价 = 原价 × 折扣 | ✅ |
| 百分数 | 部分 = 整体 × 百分率；百分率 = 部分 ÷ 整体 | ✅ |

### 2.7 速算规律

- × 5 = × 10 ÷ 2；× 15 = × 10 + × 5；× 25 = × 100 ÷ 4；× 125 = × 1000 ÷ 8
- × 11：两头一拉，中间相加；× 101：两位一隔，隔位加一
