术语表

70 条小学常用数学术语，按拼音首字母分组，给出中英对照与最早讲清它的知识点。

B

术语英文 / 含义出处
不确定事件uncertain event
可能发生也可能不发生的事件		确定事件与可能性的大小
倍数multiple
一个整数能被另一个整数整除，前者就是后者的倍数		因数、倍数与最大公因数、最小公倍数
半径radius
连接圆心和圆上任意一点的线段		圆的特征与扇形的认识
比ratio
两个数相除又叫两个数的比，写作 a:b		比的意义、化简与正反比例
比例proportion
表示两个比相等的式子		比的意义、化简与正反比例
比例尺scale
图上距离与实际距离的比		比例尺、按比例分配与杠杆平衡
百分数percentage
表示一个数是另一个数的百分之几，也叫百分率		百分数的意义
表面积surface area
立体图形所有面的面积之和		长方体和正方体的认识、表面积与体积

C

术语英文 / 含义出处
差difference
减法运算的结果		四则运算的意义
抽屉原理pigeonhole principle
把多于 n 个物体放进 n 个抽屉，至少有一个抽屉里有两个或更多物体		抽屉原理与最不利原则
长方体cuboid
六个面都是长方形（也可能有两个面是正方形）的立体图形		长方体和正方体的认识、表面积与体积
除数divisor
除法算式中除号后面的数		除法的初步认识与用口诀求商
除法division
已知积和一个因数，求另一个因数的运算		除法的初步认识与用口诀求商

D

术语英文 / 含义出处
倒数reciprocal
乘积是 1 的两个数互为倒数		分数乘法与分数除法的算理

F

术语英文 / 含义出处
分子numerator
分数线上面、表示取了几份的数		分数的初步认识与分数和除法的关系
分数fraction
把单位「1」平均分成若干份，表示其中一份或几份的数		分数的初步认识与分数和除法的关系
分母denominator
分数线上面的数叫分子，下面的数叫分母		分数的初步认识与分数和除法的关系
放大与缩小enlargement and reduction
按一定的比把图形的各边放大或缩小，形状不变		图形的放大与缩小和图形密铺
方程equation
含有未知数的等式		用字母表示数与方程的意义
负数negative number
小于 0 的数，前面带负号		正数和负数

G

术语英文 / 含义出处

几个数公有的倍数，其中最小的是最小公倍数		因数、倍数与最大公因数、最小公倍数
公因数common factor
几个数公有的因数，其中最大的是最大公因数		因数、倍数与最大公因数、最小公倍数
归一问题unitary method
先求一份是多少，再求若干份是多少的应用题		归一问题与归总问题
规律pattern
一组数或图形按某种固定方式变化的样子		算式、数列与周期中的规律
高height
从顶点向底边作的垂直线段		平行四边形、三角形与梯形的面积

H

术语英文 / 含义出处

J

术语英文 / 含义出处
奇数odd number
不能被 2 整除的整数		2、3、5 的倍数特征与质数、合数
角angle
由一个顶点引出的两条射线组成的图形		线段、射线、直线与角的认识
近似数approximate number

鸡兔同笼chickens and rabbits problem

术语英文 / 含义出处

S

术语英文 / 含义出处

十进制decimal system

术语英文 / 含义出处

统计表statistical table

通分common denominator

X

术语英文 / 含义出处

相似similarity

Y

术语英文 / 含义出处

整数除法中不能被除数整除时剩下的数，要比除数小		有余数除法的意义与余数的性质
元角分yuan, jiao, fen
人民币的单位，1 元 = 10 角，1 角 = 10 分		人民币
因数factor
能整除某个整数的整数，叫做这个数的因数		因数、倍数与最大公因数、最小公倍数
圆柱cylinder
上下两个底面是相等的圆、侧面是曲面的立体图形		圆柱和圆锥的认识与圆柱的表面积
圆锥cone
底面是圆、侧面展开是扇形、顶端是一个点的立体图形		圆柱和圆锥的体积
约分reduction of fraction
