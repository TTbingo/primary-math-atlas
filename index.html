数与代数

数的意义和性质11

  • 数的分类与意义整数、小数、分数、百分数、负数不是五个孤立的定义，而是同一批数在不同场合的几种写法。
  • 1~20 的认识数东西要一个对着一个数：点一个，数一个。数到最后一个是几，这一堆就是几个。
  • 100 以内数的组成与数位一个两位数是几个十和几个一合起来的；个位、十位、百位各有各的位置，满十就向高位搬家。
  • 万以内数的读写与组成10 个一是十、10 个十是百、10 个百是千、10 个千是万。读数时末尾的 0 不读，中间的 0 只读一个零。
  • 十进制计数法与数位顺序表满十进一、位值制：同一个数字站在不同数位上，表示的大小就相差十倍、百倍。
  • 分数的初步认识与分数和除法的关系把一个整体平均分成几份，取其中一份或几份就是分数；分母记份数、分子记几份，同分母加减只动分子。
  • 小数的认识与意义小数是「不够 1 的部分」用十进分数记下来的写法：数位越往右越小，末尾添 0 去 0 大小不变，小数点一移大小就变。
  • 亿以内数的认识与读写十万、百万、千万还是「满十进一」长出来的；数位从右边起每四位一级，分好级再读，中间末尾的 0 才不会读错。
  • 分数的意义与基本性质把单位「1」平均分成若干份，表示一份或几份的数就是分数；分数单位是其中的一份，分数和除法是一回事。
  • 百分数的意义百分数表示一个数是另一个数的百分之几，只表示倍比关系、不带单位；它与分数、小数可以互相改写。
  • 正数和负数比 0 大的数是正数，比 0 小的数是负数。负数是为了记录「相反意义的量」才被发明出来的。

数的读写1

  • 整数、小数、分数与百分数的读写读多位数只有一招：从右往左四位一级分开，万级像个数级那样读，再添一个「万」或「亿」字。

数的改写与近似数3

  • 整百整千数的加减整百数、整千数相加减，先看成「几个百」「几个千」来算：份数相加减，末尾的 0 不用数。
  • 近似数与大数的改写近似数离准确数很近但不是它；四舍五入到哪一位，就看它的下一位，五入要进一、四舍全去掉。
  • 分数、小数与百分数的互化真分数小于 1，假分数不小于 1，带分数是整数加真分数；分子除以分母，商是整饼数、余数是零块数。

比较大小1

  • 整数、小数、分数与正负数的比较大小整数先比位数，位数相同从最高位逐位比；小数先比整数部分，再比十分位、百分位，缺位补 0 不错位。

因数、倍数、质数、合数2

  • 因数、倍数与最大公因数、最小公倍数在非零自然数里，a × b = c 中的 a、b 是 c 的因数，c 是 a、b 的倍数。因数个数有限，倍数个数无限。
  • 2、3、5 的倍数特征与质数、合数2 和 5 的倍数只看个位，3 的倍数要看各位数字之和；按因数个数，自然数分成质数、合数和单独的 1。

数的运算19

  • 四则运算的意义加法把几部分合起来，减法从整体里拿走，乘法是相同加数的压缩，除法是相同减数的压缩，四则本是一条链。
  • 5 以内数的加法与减法把两堆东西合起来，求一共是多少，用加法。3 个和 2 个合起来是 5 个，写成 3 + 2 = 5。
  • 20 以内的进位加法与退位减法9 加几，先拿 1 个把 9 凑成 10，再把剩下的加上去。9 + 4 就是 10 + 3 = 13。
  • 100 以内加减法的口算与笔算竖式把数按数位竖着排好：相同数位对齐、从个位算起；加法满十进一，减法退一当十。
  • 乘法的初步认识与 1~9 的乘法口诀加法算式里的加数全都一样时，可以改写成乘法。乘法就是求几个相同加数的和的简便写法，4 个 3 相加写作 4×3。
  • 除法的初步认识与用口诀求商把一些东西分成几份，每份同样多，叫平均分。平均分才能写成除法：12 支铅笔平均分成 3 份，每份 4 支，写作 12÷3=4。
  • 乘加乘减算式里同时出现乘号和加减号时，先把乘法那一部分算成一个数，再做加减——道理在于乘法说的是「几个几」，得先打包成一堆。
  • 万以内加减法的笔算列竖式算万以内加减法：相同数位对齐、从个位算起；哪一位相加满十就向前一位进 1，哪一位不够减就从前一位退 1 当 10。
  • 有余数除法的意义与余数的性质分到不能再分，剩下不够再分一份的叫余数：11 颗糖每 3 颗一袋，装满 3 袋还剩 2 颗，写作 11÷3=3……2。
  • 多位数乘一位数与多位数乘两位数把多位数按数位拆开，每一位分别去乘，再把各份合起来；竖式只是把这件事对齐了写，满几十就往前一位进几。
  • 混合运算的顺序一道算式里既有加减又有乘除时，先算乘除、后算加减；只有同级运算，就从左边往右边依次算。
  • 除数是一位数与除数是两位数的除法除数是一位数的除法从高位除起：先分几个十，再分几个一，每一位分别平均分，再把各次分到的按数位写下来。
  • 估算估算先定数量级、再算小数字；该估大还是估小，看估错了会出什么事，钱要够、车要装得下。
  • 加法、乘法的运算律与减法、除法的性质加法交换律 a+b=b+a、结合律 (a+b)+c=a+(b+c)：加数怎么换位置、怎么分组，和都不变，是简便计算的法宝。
  • 乘方几个相同因数相乘可以写成乘方：2 × 2 × 2 记作 2^3。底数是那个因数，指数是有几个。
  • 小数的加法和减法小数加减法先把小数点对齐，也就是相同数位对齐，再按整数加减法算，最后在得数上点上小数点。
  • 小数乘法与小数除法的算理先把小数当成整数相乘，再按两个因数小数位数的和点上小数点——背后的道理是 0.1 × 0.1 = 0.01。
  • 分数的加法和减法分母相同的分数相加减，分母不变，只把分子相加减——分数单位一样，才能直接数有几个这样的单位。
  • 分数乘法与分数除法的算理分数乘分数，分子乘分子、分母乘分母；道理藏在「一张纸先竖着分、再横着分」的面积模型里。

解决问题14

  • 数量间的加减关系与倍的关系求一个数比另一个数多几或少几，用大数减小数；反过来求多几的数是多少，就用原来的数加上多出的部分。
  • 人民币、时、分、秒与年月日元、角、分是十进的钱币单位，1 元 = 10 角，1 角 = 10 分。买东西算总价、付钱找零，都在这套十进关系上打转。
  • 常见数量关系（总价、路程）单价 × 数量 = 总价，速度 × 时间 = 路程。两条关系式都只是「一份有多大、有几份」的现实版本，知二求一靠除法。
  • 和差、和倍与差倍问题知道两个数的和，也知道两个数的差，就能把这两个数求出来。道理只有一句：和里多装了一个差，补上它就变成两个大数。
  • 归一问题与归总问题先把「一份是多少」算出来，再拿这份去乘要求的份数。全部归一题的第一步都是同一个除法：总量 ÷ 份数 = 单一量。
  • 年龄问题年龄差永远不变，倍数一直在变。把「差不变」代进差倍模型，年龄问题就回到了和差倍。
  • 优化问题与找次品统筹安排时间：必须排队的事排成一条链，能同时干的塞进等待的空档里，卸货排队则让短的先来，等待时间最少。
  • 鸡兔同笼假设全是鸡，差出来的脚数除以 2，就是兔的只数——除的是「每只差」，不是「兔有几只脚」。
  • 盈亏问题两次分法的余缺之差，除以每份之差，就是份数；一盈一亏相加，双盈双亏大减小。
  • 植树问题植树问题不是四个公式，是一条线：先数段，再看点比段多 1、一样多，还是少 1。
  • 相遇问题与追及问题两人从两地同时相向出发，每过 1 分钟，两人之间的距离就缩短「速度和」。所以相遇时间 = 路程和 ÷ 速度和。
  • 工程问题把整件工作看作 1，工作效率就是「每天完成这件工作的几分之几」。合作效率 = 各人效率相加。
  • 利润与利息利润是卖买之间的差价，利润率拿成本作分母；利息是本金生出来的钱，利率是「一年生百分之几」。两者都是百分数，比的整体不同。
  • 浓度问题溶液 = 溶质 + 溶剂，浓度 = 溶质 ÷ 溶液 × 100%。加水时溶质不变，加糖时溶剂不变——抓住「谁没变」。

式与方程2

  • 用字母表示数与方程的意义字母能表示变化的数和数量关系；a² 是 a 乘 a，2a 是 a 加 a，一字之差意思完全不同。
  • 列方程解应用题列方程解应用题的关键不是解方程，而是找等量关系；把要求的量设成 x，题目怎么说就怎么写。

比和比例2

  • 比的意义、化简与正反比例两个数相除又叫两个数的比，比表示两个量的倍比关系而不是一个数；用比的基本性质可以把比化成最简整数比。
  • 比例尺、按比例分配与杠杆平衡图上距离与实际距离的比就是比例尺；前项为 1 是缩小，后项为 1 是放大，动笔之前先把单位统一成厘米。

图形与几何

图形的认识与测量11

  • 认识平面图形与克、千克、吨从立体图形描出它的面，就得到平面图形：长方形、正方形、三角形、圆。认准这四种形状，再把它们拼成七巧板那样的小图案。
  • 长度单位：厘米、米、毫米、分米与千米用拃、用铅笔量同一张课桌，报出来的数不一样，所以要有统一的长度单位。1 米 = 100 厘米，短的用厘米，长的用米。
  • 线段、射线、直线与角的认识线段有两个端点、能量出长度；射线只有一个端点，直线一个也没有，都无限延伸、量不出长度。两点之间线段最短。
  • 周长的认识与长方形、正方形的周长周长是封闭图形一周边线的总长度。它量的是「边」，不是「面」，所以单位是长度单位。
  • 面积、面积单位与长方形正方形的面积面积说的是一个面有多大。要量它，就得拿一个同样大的小正方形去铺，这个小正方形的大小就是面积单位。
  • 平行与垂直、平行四边形和梯形的认识同一平面内，两条直线要么相交、要么不相交。不相交叫互相平行，相交成直角叫互相垂直，垂线段最短。
  • 三角形的认识、内角和与三边关系三角形由三条线段围成。按角分有锐角、直角、钝角三角形；按边分有不等边、等腰和等边三角形，等边是特殊的等腰。
  • 平行四边形、三角形与梯形的面积沿高剪一刀，把三角形平移到另一边，平行四边形就变成长方形，所以面积 = 底 × 高。
  • 组合图形与不规则图形的面积组合图形没有现成公式：割成几个基本图形相加，或补成一个大图形再减去多出来的部分，两条路答案一样。
  • 圆的特征与扇形的认识圆心决定圆画在哪里，半径决定圆画多大。同一个圆里半径全都相等，直径是半径的两倍。
  • 圆的周长与圆的面积圆的周长总是直径的 π 倍：C = π d = 2π r；π 是周长与直径的固定比值，3.14 是近似值。

立体图形6

  • 认识立体图形长方体、正方体、圆柱、球是生活中常见的立体图形：它们都能立住、能装东西，滚不滚、怎么分类，一看就明白。
  • 观察物体同一个物体，从前面、左面、上面看，形状往往不同；看到的方格数也不等于小正方体的个数，被挡住的看不见。
  • 长方体和正方体的认识、表面积与体积长方体有 6 个面、12 条棱、8 个顶点，相对的面完全相同；12 条棱正好分成 3 组，每组 4 条。正方体是它的特殊情况。
  • 体积和体积单位与不规则物体的体积物体所占空间的大小叫体积，体积单位是棱长 1 的正方体；1 \textdm^3 = 1000 \textcm^3，1 \textdm^3 = 1 \textL。
  • 圆柱和圆锥的认识与圆柱的表面积圆柱由两个全等的圆和一个曲面围成，侧面展开是长方形；圆锥只有一个圆底面和一个顶点，侧面展开是扇形。
  • 圆柱和圆锥的体积把圆柱切成许多小块拼成近似长方体，底面积不变、高不变，所以 V = Sh = π r^2 h。

图形的变换与运动2

  • 轴对称、平移和旋转沿一条直线对折后两边能完全重合的图形叫轴对称图形，那条直线叫对称轴。
  • 图形的放大与缩小和图形密铺放大缩小要每条边按相同的比变化。只变长不变宽，图形就变形了——形状不变才是关键。

图形与位置1

  • 方向与位置、用数对确定位置和描述路线先用八个方向大致定位，再配上角度和距离精确描述：「北偏东 30°，距离 500 米」。

统计与概率

数据的收集与整理1

  • 数据的收集、整理与统计表统计不是从画图开始的，是从一个问题开始的。想知道什么，才决定收集什么、按什么标准分类；分法可以不同，但不重不漏，合起来永远是同一批数据。

统计图2

  • 条形统计图与折线统计图用直条的长短表示数量的多少。四条直条一样宽、间隔一样、都从 0 出发，长短才当得了尺子；读图第一步，是看清一格代表几。
  • 扇形统计图与统计图的选择用整个圆表示总数、用扇形表示各部分占总数的百分比；它只看得出占比，看不出具体数量，要算人数还得乘总数。

平均数1

  • 平均数的意义与求法平均数就是把总数重新分配成同样多以后每份的数，用总数 ÷ 份数求。它代表一组数据的整体水平，不是其中某一个。

可能性2

  • 数字编码用一组符号唯一地表示一件事，就是编码。编得好要满足两条：唯一、不重复；再用「位数够、好记、有含义」把它做得更实用。
  • 确定事件与可能性的大小一件事会不会发生，分三种：一定、不可能、可能。判断的依据不是「我见过没有」，而是「在这个条件下，所有可能的结果里有几种」。

数学思考

数学思想和方法1

  • 常用的数学思想和方法转化、数形结合、对应、列表、分析综合——五种不写在题目里、却决定你从哪儿下手的方法。

探索规律2

  • 算式、数列与周期中的规律1×1、11×11、111×111 的结果排成一座山——算式也有规律，但规律有边界，一进位就变样。
  • 数图形中的规律与推理线段、角、三角形，数法其实是同一套：固定一个起点，按顺序配对——不重不漏靠顺序，不靠眼力。

计数方法2

  • 加法原理与乘法原理做完一件事有几种办法？如果这些办法能分成互不重叠的几类，而每一类单独就能把事做完，那么总办法数就是把各类的办法数加起来。
  • 排列与组合、集合与重叠问题同样是从几个人里挑出几个：顺序算数的叫排列，用连乘；顺序不算数的叫组合，连乘之后还要除掉同一组人自己排队的次数。

抽屉原理1

  • 抽屉原理与最不利原则东西比抽屉多，就一定有一个抽屉里至少放了两个。这不是算出来的，是「怎么躲都躲不过」逼出来的。
